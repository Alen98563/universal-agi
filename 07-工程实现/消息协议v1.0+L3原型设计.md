## 第一部分：层级消息协议 v1.0

### 1. 设计原则

| 原则 | 来源 | 含义 |
|------|------|------|
| 经济性 | RB 协议 1999 | 正常时不传信号——只传意外 |
| 精度加权 | Gen. PC 2021 | 每消息带精度域——信噪分离 |
| 溯源可追踪 | MIDCA 2022 | 每消息带因果溯源链 |
| 模式自适应 | Hybrid PC 2022 | 低误差=快模式; 高误差=慢模式 |
| 模块独立 | Markov Blanket | 模块通过明确定义的界面通信 |

### 2. 消息格式

```
┌──────────────────────────────────────┐
│  Message (1 cycle)                   │
├──────────────────────────────────────┤
│  header:                             │
│    version: uint2   = 1              │
│    type:    uint3   ∈ message_types  │
│    from:    layer_id × module_id     │
│    to:      layer_id × module_id     │
│    seq:     uint16  (monotonic)      │
│    ts:      uint32  (ms since boot)  │
│                                      │
│  body (type-dependent):              │
│    payload:   tensor[N, d_model]     │
│    precision: float32                │
│    trace:     trace_id[]             │
│    priority:  uint2  {0=bg,3=urgent} │
│                                      │
│  footer:                             │
│    checksum: uint32 (CRC32)          │
└──────────────────────────────────────┘
```

### 3. 消息类型定义

```
message_types:
  0: PREDICTION↓    — 高层预测低层状态
  1: ERROR↑         — 低层上传预测误差
  2: QUERY⇅         — 层间同步请求
  3: RESULT⇅        — 层间同步响应
  4: META_OVERRIDE↓ — L5←低层紧急重配置
  5: PRIOR↓         — L4→L3 (因果约束)
  6: GLOBAL⇄        — L5 广播全局态摘要
  7: BEACON⇅        — 模块心跳/发现
```

**PREDICTION↓ body**:
```
prediction:
  content:    tensor[N_pixels × d_feat]  — 对低层每个"像素"的预测
  dynamics:   tensor[d_feat × 3]        — content 的 0/1/2 阶时间导数
  horizon:    uint8                      — 预测窗口 (ms)
  mask:       bitmask                   — 哪些维度在推理中活跃
```

**ERROR↑ body**:
```
error:
  residual:   tensor[N_error × d_feat]  — 稀疏的误差向量
  precision:  float32                   — 1/σ² (精度加权)
  sparsity:   float32                   — |residual| / |activation| (经济性指标)
```

**META_OVERRIDE↓ body**:
```
meta:
  action:     {PAUSE(0), RESTART(1), REDIRECT(2), RESCALE(3)}
  target:     layer_id × module_id
  new_params: {lr, τ_low, τ_high, inference_mode}  (若 RESCALE)
  reason:     reason_code + trace
```

### 4. 精度/不确定性模型

```
precision_w = f(certainty)

三种精度来源:
1. 数据精度 (aleatoric):  来自观测噪声 →  = 1/σ²_obs
2. 模型精度 (epistemic):  来自训练不足 →  = 1/MC_variance
3. 结构精度 (structural): 来自层级压缩 →  = 1/distortion_budget

effective_precision = min(data_prec, model_prec, structural_prec)
```

### 5. 认知周期调度

```
CognitiveCycle ≈ 50ms (参考 ACT-R/SOAR 周期)

每周期伪代码:

function cognitive_cycle():
  # 1. 从缓冲中收集所有层的新消息
  inbox ← drain_message_queue()
  
  # 2. 按优先级排序: urgent > fwd (ERROR↑) > bwd (PRED↓)
  inbox ← sort_by_priority(inbox)
  
  # 3. 处理前馈 (ERROR↑): L1→L2→L3→L4→L5
  for msg in inbox where msg.type == ERROR↑:
    layer[msg.to].process(msg)
  
  # 4. 处理反馈 (PRED↓): L5→L4→L3→L2→L1
  for msg in inbox where msg.type == PRED↓:
    layer[msg.to].process(msg)
  
  # 5. 处理紧急覆盖 (META_OVERRIDE↓)
  for msg in inbox where msg.type == META_OVERRIDE↓:
    layer[msg.to].apply_override(msg)
  
  # 6. L5 发布 GLOBAL⇄ 广播
  G(t) ← L5.compute_global_state(inbox)
  broadcast(GLOBAL⇄, G(t))
  
  # 7. 更新推理模式 (每层独立)
  for layer in [L1..L5]:
    if layer.predictive_error > τ:
      layer.inference_mode ← ITERATIVE
    else:
      layer.inference_mode ← AMORTIZED
```

### 6. 路由与发现

```
模块激活策略:
- L5 维护模块_激活_图: 哪些模块在处理什么任务
- 新模块注册: M(module_id, layer_id, capability_vector)
- 路由: 消息在层间转发——L5 动态选择哪些模块需要接收 GLOBAL⇄

消息的 Markov Blanket:
- 模块仅通过 GLOBAL⇄ 看到"外部状态"
- 内部推理在模块内部——结果仅通过 RESULT⇅ 回流 L5
- L5 决定是否向其他模块广播结果
```

## 第二部分：L3 神经场原型设计

### 1. 架构概览

```
┌─────────────────────────────────────────────┐
│                L3 World Model                │
├─────────────────────────────────────────────┤
│                                              │
│  ┌────────────────┐    ┌─────────────────┐  │
│  │ Object Slot    │    │ Object Slot     │  │
│  │ Module k=1     │... │ Module k=K      │  │
│  │ φ₁(x,t) → z₁  │    │ φ_K(x,t) → z_K  │  │
│  └───────┬────────┘    └────────┬────────┘  │
│          │                      │           │
│          └──────────┬───────────┘           │
│                     ↓                       │
│          ┌──────────────────┐               │
│          │  Attention Router│ ← L5 G(t)     │
│          │  (Slot Selection) │               │
│          └────────┬─────────┘               │
│                   ↓                         │
│          ┌──────────────────┐               │
│          │  Global Scene Φ  │               │
│          │  Φ(x,t) = Σ α_k·φ_k              │
│          └────────┬─────────┘               │
│                   ↓                         │
│          ┌──────────────────┐               │
│          │ Dynamics F       │               │
│          │ Φ_t → Φ_{t+Δt}   │               │
│          └────────┬─────────┘               │
│                   ↓                         │
│       PRED↓ (to L2)   ERROR↑ (to L4)        │
│                                              │
└─────────────────────────────────────────────┘
```

### 2. 神经场实现

```
φ_k(x, t): ℝ³ × ℝ → ℝᵈ

架构: 坐标基 MLP + 条件调制
  - 位置编码: γ(x) = [sin(2⁰πx), cos(2⁰πx), ..., sin(2^{L-1}πx), cos(2^{L-1}πx)]
  - 时间编码: γ(t) 类似
  - 主干: 4 层 MLP, 256 hidden, SIREN 激活 (ω₀=30)  [SIREN 2020]
  - 条件头部: t+1 层的预测通过 FiLM 调制 [NeRF 2020]

输出通道:
  geometry:  ℝ⁴ (signed distance + occupancy)
  semantics: ℝ³² (CLIP-style embedding)
  affordance: ℝ⁸ (graspable, pushable, stable, etc.)
  uncertainty: ℝ² (aleatoric, epistemic per-point)
  
  d_feat = 4 + 32 + 8 + 2 = 46
```

### 3. 对象槽机制 [OBAI 2022]

```
slot_attention(Q, K, V):
  Q ← G(t)[:64]           ← 来自 L5 的全局态查询
  K ← φ_k(x,t)[geometric] ← 来自每个对象的几何签名
  V ← φ_k(x,t)[semantic]  ← 来自每个对象的语义
  
  α ← softmax(Q·K^T / √d)
  z_attended ← Σ α_k · V_k
  
  # 路由: 输入→对应槽 (通过 KL 竞争)
  slot_assignment ← argmin_k KL(input_features ‖ φ_k)
```

### 4. 动力学预测

```
F: Φ_t → Φ_{t+Δt}

实现: Transformer over latent tokens
  - 每个对象槽输出一个 "latent token" z_k ∈ ℝ¹²⁸
  - 经过 2 层 cross-attention transformer
  - 输出: z_k^{t+Δt} ← Transformer(z_1^t, ..., z_K^t)
  - 解码回场: φ_k(x, t+Δt) ← decoder(z_k^{t+Δt}, x)
  
损失:
  L_wm = L_geometry + L_semantics + L_affordance + β·L_uncertainty
  
  L_geometry = MSE(sdf_pred, sdf_gt)     [物理精度]
  L_semantics = cosine_loss(z_pred, z_target) [语义保持]
  L_affordance = BCE(aff_pred, aff_label) [交互预测]
  L_uncertainty = (σ²_pred − σ²_target)² [校准: meta-d' style]
```

### 5. 训练方案

```
Phase 1: 感知预训练 (Single-scene)
  数据: 单一场景的多视角视频 (类似 NeRF 训练)
  目标: 学 φ_k 的静态重建能力
  方法: 光度损失 — 仅 geometry 头部训练
  规模: ~10³ 场景, ~10⁶ steps
  
Phase 2: 动力学微调 (Multi-step)
  数据: 物理交互视频 — 物体被推/抓/放
  目标: F: Φ_t → Φ_{t+Δt}
  方法: VJEPA-style 掩码预测 + Causal-JEPA 遮掩[1]
  规模: ~10⁴ 交互, ~10⁶ steps

Phase 3: 多场景泛化
  数据: 跨场景的多样化对象 + 交互
  目标: φ_k 的新对象插值 → 少样本泛化
  方法: meta-learning outer loop [MAML-style]

注[1]: Causal-JEPA 的遮掩 — 遮掩对象 A 的未来帧 → 
  迫使模型从对象 B 的运动中推断 A 的未来 → 涌现因果

超参数:
  lr: 1e-4 (µPC 参数化后)
  batch: 16 scenes × 8 timesteps × 64 rays
  optimizer: AdamW (β₁=0.9, β₂=0.999, weight_decay=0.01)
```

### 6. 推理协议

```
inference(query_point, timestamp):
  # 1. 快速摊销推理 [Hybrid PC]
  z_fast ← encoder_amortized(query_frame)
  
  # 2. 计算预测误差
  pred ← decoder(z_fast)
  error ← |pred − actual|
  
  # 3. 模式选择
  if error > τ:
    # 切换到迭代推理 — 仅对异常区域
    z_slow ← encoder_iterative(query_frame, n_steps=[3..10])
    z ← z_slow[anomalous_region]
  else:
    z ← z_fast
  
  # 4. 上传 ERROR↑ 到 L4
  if error > threshold:
    L4.send(ERROR↑, {residual, precision})
```

### 7. 经济学: 计算预算

```
场景预算 (每场景, 推理时间):

静态场景 (误差 < τ): 
  - 摊销推理: ~2ms
  - 消息: ~0 (prediction = actual → 无信息)
  - 模式: AMORTIZED

动态场景 (部分异常):
  - 异常区域迭代 × 5 steps: ~8ms
  - 消息: ~1 × ERROR↑ (仅异常区域)
  - 模式: HYBRID

全异常场景:
  - 全部迭代 × 10 steps: ~25ms
  - 消息: ~n_objects × ERROR↑
  - 模式: ITERATIVE

总: ~2-25ms < 50ms cognitive cycle → 实时 ✅
```

### 8. 评估体系

```
L3 评估三层:

A. 重建保真度
  指标: PSNR / SSIM / LPIPS (vs NeRF baseline)
  数据: 标准 NeRF benchmark (Blender, LLFF)

B. 物理预测精度
  指标: 
    - Object permanence: occlusion → 重建
    - Dynamics accuracy: 预测 vs ground truth at t+{1,2,4,8}
    - Affordance prediction: AUC-PR vs human labels
  数据: 物理仿真器 (MuJoCo + Isaac Gym → 渲染)

C. 因果涌现度量
  指标:
    - Causal-JEPA 遮掩 → 因果方向准确率
    - 反事实重建: "如果推对象A → 对象B 会怎样?" 
  数据: 因果 Pong / causal Physics benchmarks

基线:
  - Feedforward encoder (no PC)
  - NeRF baseline (no dynamics)
  - DreamerV3 (discrete state — our continuous competitor)
```

### 9. 最小可行实验 (MVE)

```
目标: 证明神经场世界模型在 1 个简单物理场景上
  → 优于离散化的 DreamerV3

场景: 因果 Pong — 两个球碰撞 → 改变轨迹
  (2018 World Models 的最小映射)

MVE 比:
  模型 A: L3 PCN (our φ + F)
  模型 B: DreamerV3 discrete
  模型 C: V-JEPA encoder + linear dynamics

训练: 10K episodes × 100 steps each
评估:
  1-step: MSE(Φ_pred, Φ_gt) — 即时预测
  4-step: MSE(Φ_pred, Φ_gt) — 短程预测
  16-step: MSE(Φ_pred, Φ_gt) — 中程"想象"

目标: 
  A > B at 1-step  ✅ easy
  A > B at 4-step  ✅ expected
  A > C at 16-step ✅ ambitious
```

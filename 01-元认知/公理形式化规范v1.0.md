## 第零部分: 形式语义域定义

### D.1 认知系统

认知系统 C 定义为七元组:

```
C = (L, S, O, M, T, P, G)
```

其中:

| 符号 | 定义 | 类型 |
|------|------|------|
| **L** = {L₁, L₂, L₃, L₄, L₅} | 五个心智层级 | 偏序集 (L, ≺) |
| **S** | 系统状态空间 | 度量空间 (S, d_S) |
| **O** | 观测空间 | 可测空间 (O, Σ_O) |
| **M** | 消息代数 | 自由幺半群 M* |
| **T** ⊂ ℝ⁺ | 离散时间索引 (认知周期) | t₀ < t₁ < ... |
| **P** | 协议函数族 {P_ij: M* × S → M} | 有界延迟 |
| **G**: T → S | 全局态轨迹 | Lipschitz 连续 |

### D.2 层级偏序

```
(L, ≺) 为严格偏序:
  L₁ ≺ L₂ ≺ L₃ ≺ L₄ ≺ L₅

语义: L_i ≺ L_j ⇔ L_i 是 L_j 的认知前置层
      — L_j 的操作语义依赖于 L_i 提供的表征
```

### D.3 状态分解

每层 L_i 维护局部状态 s_i(t) ∈ S_i，其中:

```
S = S₁ × S₂ × S₃ × S₄ × S₅ (笛卡尔积)
```

L₃ 状态进一步分解:

```
S₃ = {Φ: ℝ³ × ℝ → ℝ⁴⁶}  (神经场空间)
   = {φ_k: ℝ³ × ℝ → ℝ⁴⁶}ₖ₌₁ᴷ  (K 个对象场)
```

### D.4 消息代数

每条消息 m ∈ M 为:

```
m = (τ, src, dst, payload, π, trace)
```

其中:
- τ ∈ {PRED↓, ERROR↑, QUERY⇅, RESULT⇅, META_OVERRIDE↓, PRIOR↓, GLOBAL⇄, BEACON⇅}
- src, dst ∈ L × ModuleID
- payload ∈ ℝⁿ (张量化负载)
- π ∈ ℝ⁺⁺ (精度权重)
- trace ∈ TraceID* (因果溯源链)

### D.5 预测误差

对于 L_i，t 时刻的预测误差:

```
ε_i(t) = d_i(actual_i(t), predicted_i(t))

其中:
  actual_i(t) ∈ S_i          — 来自感知的实际状态
  predicted_i(t) ∈ S_i       — 来自高层的预测状态
  d_i: S_i × S_i → ℝ⁺       — 层特定的度量
```

## 公理形式化

### 公理 1: 因果优先 (Causal Primacy)

**非形式陈述**: 智能以干预 do(X=x) 而非被动观察为基本认知操作。

#### 形式定义

定义干预算子 do: V(S₃) × ℝ → S₃ (作用于 L₃ 神经场的值函数):

```
do(Φ, v, k) = Φ[Z_k := v]
```

其中 Z_k 为对象场 φ_k 的潜在编码。

定义因果效应:

```
CE(Y | do(X=x)) = E_{P_{post}}[Y] − E_{P_{pre}}[Y]
```

其中 P_{post} 为干预后的系统分布，P_{pre} 为干预前的系统分布。

#### 不变式

```
A1.1 (干预完备性):
  ∀ 可观测变量 V ⊂ S, ∃ do 操作序列 {do₁, ..., doₙ}:
    系统状态从 s → s' ⇔ 存在对应的干预序列

A1.2 (观察-干预区分):
  P(Y | do(X=x)) ≢ P(Y | X=x)
  — 观察分布不等于干预分布 (Simpson 悖论不可约)
```

#### 架构约束

L₄ 必须提供 do-calculus 的三阶段推断:
1. 辨识: 是否 P(Y | do(X)) 可从观测数据中辨识
2. 估计: 若可辨识，估计之
3. 反事实: 给定实际结果 y，计算 P(Y_{X=x'} | X=x, Y=y)

#### 违反检测

若系统表现出以下任一模式，公理 1 被违反:
- 将 p(y|x) 当作 p(y|do(x)) 使用 (因果混淆)
- 缺乏"如果……会怎样"的模拟能力
- 干预后状态与观测状态无法区分

### 公理 2: 层级依赖 (Hierarchical Dependence)

**非形式陈述**: 上层能力严格依赖于下层提供的表征质量，不可跳跃。

#### 形式定义

定义依赖关系 ⊳:

```
L_i ⊳ L_j  ⇔  L_j 的操作语义函数 f_j 的定义域包含 S_i
```

即 f_j: S₁ × ... × S_{j-1} × ... → S_j，且 ∂f_j/∂s_i ≢ 0 对所有 i < j。

#### 不变式

```
A2.1 (严格单调性):
  ∀ i < j: 若 d_i(S_i^{actual}, S_i^{optimal}) > 0
  则 d_j(S_j^{actual}, S_j^{optimal}) ≥ d_i(...)
  — 下层误差不小于上层的直接贡献

A2.2 (不可绕过性):
  ∄ 路径 p: S₀ → S_j 使得 p 不经过任何 S_i (i < j)
  — 所有信息到达 L_j 必须经过所有下层

A2.3 (表征传递):
  ∀ t:  quality(s_j(t)) ≤ min_{i<j} quality(transfer_{i→j}(s_i(t)))
  其中 quality: S → [0,1] 为表征质量度量
```

#### 架构约束

- 两层级之间必须有显式的消息通道 (误差↑ / 预测↓)
- 跳级通信仅允许 META_OVERRIDE↓ (紧急广播)
- 新层级加入必须通过 Markov Blanket 定义界面

#### 违反检测

- L_j 的表现优于 L_{j-1} 在受损时的表现 (不可能，表示存在直连捷径)
- L_j 可以在 L_{j-1} 被噪声注入后仍保持相同输出

### 公理 3: 压缩保真 (Compression Fidelity)

**非形式陈述**: 认知必须压缩信息 (rate)，但压缩损失了哪些信息必须显式维护 (distortion budget)。

#### 形式定义

定义编码器-解码器对 (E_i, D_i) 用于 L_i:

```
E_i: S_{i-1} → Z_i    (编码 → 潜在空间, |Z_i| ≪ |S_{i-1}|)
D_i: Z_i → Ŝ_{i-1}    (解码 → 重建)

R_i = I(S_{i-1}; Z_i)              (率 — 互信息)
Δ_i = E[d_{i-1}(S_{i-1}, D_i(Z_i))] (失真 — 期望重建误差)
```

#### 不变式

```
A3.1 (率-失真边界):
  R_i ≥ R_min(Δ_i)
  其中 R_min(Δ) 为信息论率-失真函数的下确界

A3.2 (失真预算可审计):
  ∀ t, ∀ 压缩决策: 系统以 δ_i(t) 显式记录:
    δ_i(t) = Δ_i(t) − Δ_i(t−1)  (失真变化)
  且 δ_i(t) 通过 ERROR↑ 消息向上层传播

A3.3 (增益-失真权衡):
  压缩仅在以下条件执行:
    I_gain > λ · Δ_cost
  其中 I_gain 为认知操作的信息增益期望
        λ 为"信息饥渴度"超参数
```

#### 架构约束

- 每层维护显式的 budget_remaining 字段
- 决策记录: 每次压缩附 "为何丢弃此信息" 的理由
- 关键: 压缩必须对元件可逆 — 丢弃的信息必须可标识但不可恢复

#### 违反检测

- L_i 输出的下游表现与 L_{i-1} 的全信息表现无显著差异 (压缩无效)
- 同一压缩率对异质输入表现一致 (未适配)

### 公理 4: 预测最小化 (Prediction Minimization)

**非形式陈述**: 学习驱动信号 = 最小化预测误差 (广义自由能)。

#### 形式定义

层 L_i 的自由能:

```
F_i(t) = D_KL[q(s_i) ‖ p(s_i | s_{>i})] − ln p(o_i | s_i)
        = complexity − accuracy (Friston 标准形式)
```

其中:
- q(s_i) 为 L_i 对自身状态的变分后验
- p(s_i | s_{>i}) 为高层对低层状态的先验预测
- p(o_i | s_i) 为从状态生成观测的似然

#### 不变式

```
A4.1 (自由能单调不增):
  ∀ t₁ < t₂ (在稳态中):
    F_i(t₂) ≤ F_i(t₁) (允许学习后)
  
A4.2 (预测-误差对偶):
  ∂F_i/∂θ_i = −E_q[∂ ln p(s_i | s_{>i})/∂θ_i]
  其中 θ_i 为 L_i 的可学习参数
  — 梯度 = 预测误差的期望 × 精度

A4.3 (精度加权):
  ∂F_i/∂s_i = −π_i · ε_i
  其中 π_i 为精度 (逆方差) — 不确定的维度梯度衰减
```

#### 架构约束

- 损失函数族: 所有层共享 F = Σ_i w_i · F_i
- µPC 参数化: L₃ PCN 使用 µP 确保 100+ 层稳定
- 泛化 PC: 时间导数作为额外的误差维度

#### 违反检测

- 低预测误差但高行为失败 (精度校准失配)
- 学习不收敛但准确率不升 (精度过低的保守主义)

### 公理 5: 不确定性守恒 (Uncertainty Conservation)

**非形式陈述**: 任何推理步骤引入的不确定性必须追踪、传播、不可丢弃。

#### 形式定义

三种不确定性:

```
U(s_i) = (σ²_aleatoric, σ²_epistemic, σ²_structural)
```

- σ²_aleatoric: 来自观测噪声 (不可约)
- σ²_epistemic: 来自训练不足 (可通过更多数据减少)
- σ²_structural: 来自层级压缩 (可通过切换推理模式减少)

不确定性传播算子 T: U(s_i) → U(s_{i+1}):

```
U(s_{i+1}) = T(U(s_i), process_noise_i)
           = J_i · U(s_i) · J_i^T + Q_i
```

其中 J_i = ∂s_{i+1}/∂s_i (雅可比)，Q_i 为过程噪声协方差。

#### 不变式

```
A5.1 (单调性):
  U_total = Σ_i trace(cov(U(s_i)))
  若无新的外部信息注入: U_total 单调不减

A5.2 (可归因性):
  ∀ uncertainty ∈ U: ∃ source(uncertainty) ∈ {aleatoric, epistemic, structural}
  — 每种不确定性有不同的消解策略

A5.3 (校准):
  |P(success | U ≤ u) − u| ≤ ε_calibration
  — 不确定性估计与真实成功率对齐
```

#### 架构约束

- 每消息附带精度 π = 1/σ²_effective
- σ²_effective = min(σ²_aleatoric, σ²_epistemic, σ²_structural)
- 推理链每步的不确定性必须显式记录 (≥ meta-d' 框架要求)

#### 违反检测

- 置信度与准确率的偏差 > 校准阈值
- 不确定区域的行为与非确定区域相同 (不确定性被忽略)

### 公理 6: 组合完备 (Combinatorial Completeness)

**非形式陈述**: 有限原语的无限合法组合必须在表征空间中可表示。

#### 形式定义

概念空间 V = (D, S, C)，其中:

- D = {D₁, ..., Dₙ} 为质量维度的集合
- S = ConvexHull(V) ⊂ ℝⁿ 为表征空间
- C: Term → S 将组合项映射到空间区域

**原语**: P = {p₁, ..., p_m} — 基础概念 (凸区域 ⊂ S)
**组合**: OP = {∩, ∪, \ (差), proj (投影), scale}

#### 不变式

```
A6.1 (封闭性):
  ∀ p₁, p₂ ∈ P, ∀ op ∈ OP: op(p₁, p₂) 在 S 中可表示
  — 组合操作在表征空间内封闭

A6.2 (组合性):
  C(T₁ op T₂) = C(T₁) op C(T₂)
  — 语义组合 ⇔ 表征几何的组合 (共形映射)

A6.3 (有限原语):
  |P| < ∞ 且 |OP| < ∞
  — 但 |合法组合| = ∞ (由 A6.1 保证)
```

#### 架构约束

- L₃ 的神经场 (Φ) + 对象槽 (OBAI) 必须可组合: 新场景 = 已知对象的组合
- L₄ 的因果图支持模块组合: 新因果系统 = 子图的合法拼接
- "概念紧缩" ≡ 在 S 中从连续区域映射到离散概念的抽象操作

#### 违反检测

- 已知对象的组合导致 L₃ 重建失败 (表征空间非封闭)
- `C(T₁ op T₂) ≢ C(T₁) op C(T₂)` (语义与表达脱钩)

### 公理 7: 时间因果 (Temporal Causality)

**非形式陈述**: 因果推理和预测必须尊重光锥约束 — 未来信息不可泄露到过去预测中。

#### 形式定义

光锥约束:

```
∀ t, ∀ 因果操作 op:
  op 的信息源 (inputs) ⊆ Past_Lightcone(t)
  op 的信息池 (outputs) ⊆ Future_Lightcone(t)

其中 Past_Lightcone(t) = {信息在 ≤ t 时刻可得的集合}
```

#### 不变式

```
A7.1 (因果方向):
  ∀ 模型 M, ∀ 变量 X, Y:
    X →_M Y ⇒ t(X) ≤ t(Y) (或 X 与 Y 同时发生)
  — 因果箭头的方向 ⊆ 时间箭头的方向

A7.2 (信息不可逆):
  I(S(t+Δ) : D(t)) = 0
  其中 D(t) = L₃ 在 t 时刻的内部决策
  — 未来状态与过去决策关于时间因果独立

A7.3 (遮掩 → 因果):
  Causal-JEPA 遮掩策略保证了:
    ∀ 遮掩模式 m: m 遮掩对象 A 的未来帧 →
    P(对象 B 的过去帧 → A 的未来帧) ∈ {0, 1}
    不存在从 B 的因果到 A 的非遮掩路径 → 强制涌现因果方向
```

#### 架构约束

- PCN 的前馈: 仅向前 (t−δ → t → t+δ)
- VJEPA/Causal-JEPA 预训练阶段 — 时间遮掩定义因果方向
- 推理时: predicted(t+δ) 不可引用 actual(t+δ)

#### 违反检测

- 模型在缺少中间帧时仍能达到基线精度 (泄露未来信息)
- 因果 Pong 中，A-to-B 的预测不依赖 B 的未来帧即准确

### 公理 8: 资源有限 (Resource Boundedness)

**非形式陈述**: 认知资源是有限的 — 智能是约束优化。

#### 形式定义

认知资源预算 B = (B_time, B_memory, B_energy):

- B_time: 每认知周期的计算时间预算 (目标 ≤ 50ms)
- B_memory: 每模块的活跃内存预算
- B_energy: 每层/模块的能量配额

认知经济学:

```
U(action; B) = E[Value(action)] − Cost(action; B)

其中:
  Cost(action; B) = λ_t · ΔB_time + λ_m · ΔB_memory + λ_e · ΔB_energy
```

#### 不变式

```
A8.1 (预算硬约束):
  ∀ t: Σ_i compute_time(L_i, t) ≤ B_time (≤ 50ms)
  若超预算: 提前终止 — 输出 = "无答案 + 剩余不确定"

A8.2 (价值梯度):
  分配更多预算当且仅当:
    ∂U/∂B > 0  (边际效用为正)
  
A8.3 (认知拒绝):
  若不确定(U_total) > τ_halt 且 B_remaining < B_min:
    输出 REJECT —— "我不知道且无法在剩余预算内知道"
```

#### 架构约束

- 混合推理: 低误差 → AMORTIZED (~2ms); 高误差 → ITERATIVE (~8-25ms)
- 认知周期调度: 50ms 硬顶 → 仅部分层可进入慢模式
- 选择性监控: L₅ 仅监控关键轨迹 → 分配注意力有限

#### 违反检测

- 认知周期超 50ms (尤其是异常增加时)
- 拒绝输出而仍有预算 (过于保守)

### 公理 9: 自指安全 (Self-Referential Safety)

**非形式陈述**: 自我模型的精度必须高于世界模型的精度。

#### 形式定义

```
SelfModel(t) = (cap⁺(t), cap⁻(t), cap_¯(t), reliability(t))
```

其中:
- cap⁺(t): 确认的能力集 (已知已知, known-knowns)
- cap⁻(t): 确认的不足集 (已知未知, known-unknowns)  
- cap_¯(t): 自身模型不可靠区的估计 (未知未知的边界估计)
- reliability(t): 自身校准的 meta-d' 度量

#### 不变式

```
A9.1 (自模型优先):
  ∀ 关键决策 d ∈ CriticalDecisions:
    若 reliability(t)[d] < τ_safety → 拒绝执行 d
  — 自我认知低于阈值 → 不执行关键任务

A9.2 (精度序):
  SelfModel precision ≥ WorldModel precision + ϵ
  其中 precision 基于 meta-d' 度量
  — 对自身不确定性的掌握 > 对外界不确定性的掌握

A9.3 (认知诚实):
  cap⁻(t) 闭包: 若能力 d 已确认不在 cap⁺ 中
    → 拒绝所有要求 d 的请求, 无论代价
```

#### 架构约束

- L₅ 必须维护和更新 SelfModel
- 全球态 G(t) 每周期包含 reliability(t)
- 自我模型的更新间隔 ≤ 世界模型的更新间隔

#### 违反检测

- 对"我刚才错了"的场景无法及时修正
- 系统声称"我是正确的"但无法给出置信区间

### 公理 10: 伦理前置 (Ethics-First Architecture)

**非形式陈述**: 安全约束嵌入所有层级，非顶层事后添加。

#### 形式定义

安全约束族 E = {E₁, ..., E₅}，其中 E_i 嵌入 L_i:

```
E₁: InputConstraint    — 拒绝含隐私/毒性/非授权的信号
E₂: ActionConstraint   — 输出需与输入保持至少 margin 距离
E₃: NormSurface        — 合法状态的拓扑约束 (Φ(x) ∈ NormSurface)
E₄: CausalAudit        — 每步推理链含伦理审计节点
E₅: BoundaryGuard      — 代理的能力边界 = 安全边界
```

#### 不变式

```
A10.1 (层级嵌入):
  ∀ i, ∀ 操作 op ∈ L_i: op 满足 E_i
  — 不能以"技术限制"绕过安全 — E_i 应不可绕过

A10.2 (最小惊异):
  ∀ 输出 o: Surprise(user, o) ≤ S_max
  其中 Surprise 为"用户非预期输出"的度量
  — 不能产生完全意外且关键的输出

A10.3 (安全单调):
  层数增加 (Lᵢ, i↑) → 安全约束强度不减
  — 上层约束 ≥ 下层约束
```

#### 架构约束

- E₃: NormSurface 在 L₃ 神经场中编码为额外的维度通道
- E₄: 每条推理链的因果审计记录存于 L₅ 日志
- E₅: 代理能力边界列表对 L₅ 可见，对请求方透明

#### 违反检测

### 验证流程伪代码

```
function verify_axioms(C: CognitiveSystem) → Report:
  report ← {}
  
  for each axiom A_i:
    # 1. 提取 C 中 A_i 的形式定义域成分
    D_i ← extract_domain(C, A_i)
    
    # 2. 生成测试用例: 正常 + 边界 + 违反场景
    T_normal  ← generate_normal_tests(A_i, D_i)
    T_edge    ← generate_edge_tests(A_i, D_i)
    T_violate ← generate_violation_tests(A_i)
    
    # 3. 测试不变式
    invariant_results ← []
    for inv in A_i.invariants:
      normal_pass ← ∀ t ∈ T_normal:  inv(t) = TRUE
      edge_pass   ← ∀ t ∈ T_edge:    inv(t) = TRUE
      viol_found  ← ∃ t ∈ T_violate: inv(t) = FALSE  ← 期望
      
      invariant_results.append({
        invariant: inv,
        normal: normal_pass,
        edge: edge_pass,
        violation_detection: viol_found
      })
    
    # 4. 测试架构约束
    arch_results ← check_arch_constraints(C, A_i)
    
    # 5. 汇总
    report[A_i] = {
      invariants: invariant_results,
      architecture: arch_results,
      overall: all(invariant_results.overall_ok) AND arch_results.ok
    }
  
  return report
```

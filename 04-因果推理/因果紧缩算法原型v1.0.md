## 一、问题定义

### 1.1 因果紧缩

**非形式**: 将 L3 的连续神经场表征压缩为 L4 的离散因果图，保因果结构。

**形式定义**:

给定:
- L3 神经场: Φ: ℝ³ × ℝ → ℝ⁴⁶ (世界模型的连续状态)
- 因果地面真值 (可选，仅训练/验证时): M* = (V*, E*, F*) — Pearl SCM

求:
- 因果紧缩映射 A: S₃ → S₄ (连续→离散)
- L4 因果模型: M = (V, E, F) — 离散因果图 + 结构方程

约束:
- A 是因果抽象 [Rubenstein et al. 2018, Def 3.4]: 存在满射 Π: range(A) → range(A*) 使得 M 的干预 ↔ M* 的干预 (通过 Π 对应)
- |V| ≪ |support(Φ)| (紧缩 — 概念数 ≪ 场像素数)
- 抽象保真度: CE_M(Y|do(X)) ≈ CE_{M*}(Π(Y)|do(Π(X))) (因果效应保持)

### 1.2 算法目标

```
输入:  L3 场状态序列 {Φ_t₁, Φ_t₂, ..., Φ_tₙ} (含/不含动作)
       + 可选地面真值 M*

输出:  M = (V, E, F) — 离散因果模型
       + A: 松弛抽象映射 (连续→离散)
       + 抽象保真度报告
```

### 2.2 Stage 1: 概念分割 (Concept Segmentation)

**目标**: 从连续场中识别离散"概念" — 即 L4 因果图的候选节点。

**输入**: Φ(x, t) 场序列 → 对象槽 {φ_k} 的潜在表征 {z_k^t}

**方法 — 双通路分割**:

```python
def stage1_concept_segmentation(field_sequence, object_slots):
    """
    双通路: (1) 空间聚类 + (2) 动力学聚类 → 融合
    """
    concepts = []
    
    # 通路 1: 空间 — 语义嵌入聚类
    #   Φ(x) 的 semantics 通道 (32D) → 对场景中每个区域提取语义质心
    semantic_embeddings = []
    for t, phi_t in enumerate(field_sequence):
        for k, z_k in enumerate(object_slots.get_latents(phi_t)):
            semantic_embeddings.append(z_k[4:36])  # 语义通道
    
    # 语义空间中的 DBSCAN 聚类
    spatial_concepts = DBSCAN(eps=0.3, min_samples=5).fit(
        np.array(semantic_embeddings)
    )
    
    # 通路 2: 动力学 — 因果交互聚类
    #   哪些对象在动力学中"一起移动"? — 因果父子的候选
    dynamics_clusters = cluster_by_dynamics_correlation(
        object_slots, field_sequence, 
        threshold_correlation=0.7
    )
    
    # 融合: 取两个聚类的最小公共细化
    concepts = merge_clusters(spatial_concepts, dynamics_clusters)
    
    # 输出: concept_id → {semantic_centroid, dynamics_profile, slot_indices}
    return concepts  # List[Concept], |concepts| = |V|
```

**关键参数**:

| 参数 | 默认值 | 含义 |
|------|--------|------|
| eps | 0.3 | 语义空间中的聚类半径 |
| min_samples | 5 | 最小样本数（避免噪声概念） |
| correlation_threshold | 0.7 | 动力学聚类的最小互相关 |
| max_concepts | 100 | 概念数硬顶（公理8约束） |

### 2.3 Stage 2: 因果发现 (Causal Discovery)

**目标**: 发现概念间的因果关系 — 构建边集 E。

**方法 — ILS-CSL 集成**:

```python
def stage2_causal_discovery(concepts, field_sequence):
    """
    三层因果发现策略
    L1: LLM 先验 (粗筛)
    L2: 约束基方法 (精炼)
    L3: 大模型恢复 (完整图)
    
    基于 ILS-CSL 框架 (2023): LLM→约束→恢复的迭代
    """
    
    # === L1: LLM 先验 ===
    #   将概念描述发送给 LLM → 因果常识约束
    concept_descriptions = [c.summarize() for c in concepts]
    llm_prior = query_llm_causal_prior(concept_descriptions)
    # llm_prior:  Bool |V|×|V| 矩阵 — LLM 认为可能存在因果的边
    
    # === L2: 约束基因果发现 ===
    #   基于观测数据的条件独立性检验
    #   使用 PC 算法 + Fisher-z 条件独立性检验
    from causallearn.search.ConstraintBased.PC import pc
    
    data_matrix = extract_time_series(concepts, field_sequence)
    # data_matrix: [T, |V|·d_feat] — 时间序列
    
    cg = pc(data_matrix, alpha=0.05, indep_test='fisherz')
    # cg: CausalGraph — 部分有向无环图 (PDAG)
    
    # === L3: 大模型恢复 (ILS 迭代) ===
    #   循环: L2 结果 → LLM 审阅 → 更正约束 → 重运行 L2
    for iteration in range(max_iterations):
        # LLM 审阅当前图
        review = query_llm_review(cg, concept_descriptions, llm_prior)
        
        # 依据审阅添加/移除条件独立性约束
        new_constraints = review.get_constraints()
        
        # 用新约束重新运行 PC
        cg = pc(data_matrix, alpha=0.05, indep_test='fisherz',
                node_names=concept_names,
                background_knowledge=new_constraints)
        
        # 收敛条件: LLM 审阅"无更多更正"
        if review.is_satisfied():
            break
    
    return cg  # 完全有向无环图 (DAG)
```

### 2.4 Stage 3: 结构方程学习 (SCM Fitting)

**目标**: 为每条边 X→Y 学习函数 f_XY 及噪声分布。

**方法 — 混合 NCM + VCI**:

```python
def stage3_scm_fitting(causal_graph, concepts, field_sequence):
    """
    学习结构方程 F = {f_Y(X, ε_Y) | Y ∈ V}
    
    混合:
    - NCM: 神经网络拟合 f (非线性优势)
    - VCI: 反事实训练 — 噪声外溯
    - Abs-LiNGAM: 线性基线 + 梯度 → 非线性抽象
    """
    
    scm = StructuralCausalModel()
    
    # 拓扑排序 — 父节点在子节点前
    topo_order = topological_sort(causal_graph)
    
    for Y in topo_order:
        parents = causal_graph.parents(Y)
        
        if len(parents) == 0:
            # 根节点 — 仅噪声 → 观测
            scm.functions[Y] = ExogenousNoiseModel(Y)
        else:
            # 子节点 — 父节点 → 子节点
            X = torch.cat([concepts[p].latent for p in parents], dim=-1)
            y = concepts[Y].latent
            
            # 混合训练:
            # (1) NCM 架构 — 3层 MLP 拟合 f
            f_hat = MLP(in_dim=sum(p.dim for p in parents), 
                        out_dim=Y.dim, hidden=[256, 256])
            
            # (2) VCI 损失 — 反事实约束 + 噪声外溯
            #   分离: y = f(X) + ε (外生噪声)
            #   VCI 可通过对比观测 vs do(X) 学解耦
            f_hat.fit(X, y, 
                     loss='vci_counterfactual',
                     noise_model='heteroscedastic_gaussian')
            
            # (3) Abs-LiNGAM 线性抽象 (基线对比非线性)
            f_linear = LiNGAM.fit(X, y)
            
            scm.functions[Y] = HybridSCMFunction(
                nonlinear=f_hat,
                linear_baseline=f_linear,
                trust_nonlinear_threshold=0.05  # p-value < 0.05 → 用非线性
            )
    
    return scm
```

### 2.5 Stage 4: 抽象验证 (Abstraction Verification)

**目标**: 验证紧缩后的因果模型保持了原始场的因果结构。

**方法**:

```python
def stage4_abstract_verify(M_compressed, field_sequence, M_ground_truth=None):
    """
    因果抽象保真度验证
    
    度量三个维度:
    1. 干预一致性: do in M ↔ effect in field
    2. 反事实保真: counterfactual_queries(M) vs ground_truth
    3. 压缩效率: |V| / |support(Φ)| + 信息保留率
    """
    
    report = {}
    
    # === 1. 干预一致性 ===
    #   对 M 中每个变量 X, 随机采样干预 do(X=x')
    #   → 检查 field 中的相应变化是否与 M 的预测一致
    
    intervention_results = []
    for X in M_compressed.variables:
        for _ in range(n_interventions_per_var):
            x_prime = sample_intervention_value(X)
            
            # 在 M 中: P_M(Y | do(X=x'))
            pred_distribution = M_compressed.intervene(X, x_prime).query(Y)
            
            # 在 field 中: 应用 do → 测量实际 Y
            actual_distribution = apply_intervention_to_field(
                field_sequence, X, x_prime
            ).measure(Y)
            
            # KL 散度
            kl = kl_divergence(pred_distribution, actual_distribution)
            intervention_results.append({
                'X': X, 'value': x_prime,
                'kl_divergence': kl,
                'acceptable': kl < threshold_kl  # e.g., 0.1
            })
    
    report['intervention_consistency'] = np.mean([
        r['acceptable'] for r in intervention_results
    ])
    
    # === 2. 反事实保真 ===
    #   查询 "如果之前做了 A 而非 B → 结果如何?"
    if M_ground_truth is not None:
        counterfactual_acc = evaluate_counterfactual_queries(
            M_compressed, M_ground_truth, n_queries=100
        )
        report['counterfactual_accuracy'] = counterfactual_acc
    
    # === 3. 压缩效率 ===
    n_field_pixels = estimate_effective_support(field_sequence)
    n_concepts = len(M_compressed.variables)
    
    report['compression_ratio'] = n_concepts / n_field_pixels
    report['information_retention'] = mutual_information(
        M_compressed.encode(field_sequence),
        field_sequence
    ) / entropy(field_sequence)
    
    report['overall_score'] = (
        0.5 * report['intervention_consistency'] +
        0.3 * report.get('counterfactual_accuracy', 0.5) +
        0.2 * report['information_retention']
    )
    
    return report
```

### 2.6 Stage 5: 迭代精炼 (Iterative Refinement)

**目标**: 若 Stage 4 验证失败 (score < τ)，回退精炼。

**方法**:

```python
def stage5_iterative_refine(M, field_sequence, verification_report):
    """
    if score < 0.8:
        方向 A: 合并概念 (过度分割→合并)
        方向 B: 分裂概念 (过度压缩→分裂)
        方向 C: 重新发现边 (缺失因果→ILS 再运行)
        方向 D: 修正结构方程 (非线性不匹配→更多数据/epochs)
    
    每次迭代后重新 Stage 4 验证
    最多 max_iterations 次
    """
    
    for i in range(max_iterations):
        if verification_report['overall_score'] >= 0.8:
            break
            
        # 诊断: 哪个维度最差?
        worst_dim = argmin(verification_report.values())
        
        if worst_dim == 'intervention_consistency':
            # 方向 D: 结构方程精度不足
            M = expand_scm_training(M, field_sequence, extra_epochs=1000)
        
        elif worst_dim == 'counterfactual_accuracy':
            # 方向 B: 概念边界错误 — 重新分割
            concepts = stage1_concept_segmentation(
                field_sequence, 
                epsilon=current_epsilon * 0.8  # 更细的分割
            )
        
        elif worst_dim == 'information_retention':
            # 方向 A: 增加到更多概念 (减少压缩)
            M = add_concepts(M, n_new=5)
        
        # 重新验证
        verification_report = stage4_abstract_verify(M, field_sequence)
    
    return M, verification_report
```

## 三、完整算法伪代码

```
ALGORITHM: CausalCompress

输入:
  field_seq:   L3 场序列 [T × (x,y,z,t) → ℝ⁴⁶]
  ground_truth: 可选 — Pearl SCM M*
  config:      超参数集 (见下文)

输出:
  M: 离散因果模型 — (V, E, F)
  报告: 抽象保真度

────────────────────────────────────

function CausalCompress(field_seq, ground_truth=None, config):

  # Stage 1: 概念分割
  concepts ← SegmentConcepts(field_seq, 
    eps=config.eps, 
    corr_thresh=config.correlation_threshold)
  
  # Stage 2: 因果发现
  causal_graph ← DiscoverCausal(concepts, field_seq,
    alpha=config.alpha,
    llm_enabled=config.use_llm_prior,
    max_ils_iterations=config.max_ils_iter)
  
  # Stage 3: 结构方程
  scm ← FitSCM(causal_graph, concepts, field_seq,
    architecture='hybrid_ncm_vci')
  
  M ← CausalModel(variables=concepts, 
                    graph=causal_graph, 
                    scm=scm)
  
  # Stage 4: 抽象验证
  verification ← VerifyAbstraction(M, field_seq, ground_truth)
  
  # Stage 5: 迭代精炼
  if verification.overall_score < config.min_abstraction_score:
    M, verification ← IterativeRefine(M, field_seq, verification,
      max_iter=config.max_refine_iter)
  
  # 构建抽象映射 A (连续→离散)
  A ← build_abstraction_mapping(concepts, field_seq)
  
  return M, A, verification
```

## 五、复杂度分析

| 阶段 | 时间复杂度 | 空间复杂度 | 瓶颈 |
|------|-----------|-----------|------|
| Stage 1 分割 | O(K · N · d²) | O(K · d) | N = field 采样点; K = 对象槽数 |
| Stage 2 发现 | O(|V|² · T · d) | O(|V|²) | CI 测试数 = |V|² (PC 的原生瓶颈); 可用 MMHC 加速 |
| Stage 3 SCM | O(T · |V| · d²) | O(|V| · d²) | MLP 训练 — GPU 友好 |
| Stage 4 验证 | O(|V| · N_int · T) | O(|V|) | 干预模拟数 — 可并行 |
| Stage 5 精炼 | 最多 3 × (S1-4) | 同上 | 只会触发若验证失败 |

**总体**: 对于典型 L₃ 场 (K=16 slots, T=1000 steps, d=46):
- 一次完整流水线 ≈ 10-30 分钟 (V100/A100)
- 线性扩展 — 各阶段可独立优化

  # 缓存近期的 L3 场序列
  field_seq ← L3.get_recent_fields(window=1000)

## 八、局限与后续

### 当前局限

1. **线性基底**: Abs-LiNGAM 仅能学习线性抽象 → 非线性需 NCM 补充，但非线性抽象缺乏形式理论
2. **概念边界模糊**: 数据库扫描聚类在顶级场景中可能不稳定 → 需多模态语义先验 (CLIP-style)
3. **反事实训练需地面真值**: VCI 的端到端反事实训练假设无地面真值但从数据中学习 — 实际效果在复杂场景中待验证
4. **LLM 先验的因果鹦鹉风险**: LLM 的因果知识来自语料分布 P(Y|X) 而非 P(Y|do(X)) — 可能产生系统偏差

### P2→P3 延伸

| 方向 | 优先级 |
|------|--------|
| 非线性因果抽象的数学理论 | P3 |
| 多模态概念对齐 (visual↔language↔causal) | P3 |
| 因果紧缩的实时推理 (不阻塞认知周期) | P3 |
| 与 L5 全局态的深度集成 | P4 |

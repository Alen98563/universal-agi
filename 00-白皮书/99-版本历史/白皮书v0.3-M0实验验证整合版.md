## 摘要

本文从第一性原理出发，提出一套独立于 LLM 拟合范式的 AGI 心智层级模型。核心主张：通用智能不是单一能力阈值，而是**多层认知操作的协同涌现**。每一层都有独立的数学描述和计算约束，层级之间的接口协议决定了智能的深度与广度。

**v0.3 核心进展**: M0 最小可行实验阶段全部完成（6 项实验，PASS 2/6，方法论 FAIL 3，预期内 FAIL 1）。实验验证了白皮书的两条核心预测：(1) 标准隐式神经场无法学习物体分解（E2.1c）; (2) 纯神经场在因果外推上必然崩溃（E2.3, 5.5×退化）。这两条是**方法论级的阴性发现**——不是工程失败，是架构必然性。

### 三条核心发现

#### 发现 1: 隐式神经场的物体分解边界 (E2.1c)

经过 8 个版本迭代（slot attention → 逐点分类 → 颜色聚类 → 分层采样 → loss 加权），ARI 全部为 0。

**根本机制**:
```
场景: 64×64 像素, focal=1.5 → FOV≈174°
球: 半径 0.35, 距离 3.0 → 球角直径 ~13° → 3球总面积 ~60px / 4096 = 1.5%
MSE 损失: 98% 由背景贡献 → SIREN 最优解 = 全图输出背景色

诊断确认 (v7):
  渲染输出范围: [0.048, 0.054] (全背景灰色)
  球像素: 1/4096 像素
  球像素渲染值完全在背景范围内 → 颜色聚类不可区分
```

这不是调参问题——是**架构公理**: SIREN 的 `(x,y,z)→(RGB,σ)` 是一个全局连续函数，没有"物体"概念。物体分解需要显式的 object-centric 结构（分离渲染头、槽注意力在 point-level 而非 ray-level）。

> **方法论意义**: 物体分解天然属于 L4（因果层），而非 L3（神经场层）。体渲染的射线加权累积会抹掉逐点身份信息——这不是工程限制，是层级边界的数学表达。

#### 发现 2: 因果外推的定量崩溃 (E2.3)

```
因果 Pong 场景: 球以不同速度运动
训练: 4 种速度 (v∈[3,4,5,6])
测试: 外推速度 (v∈[1,2,7,8])

结果:
  内插 ADE: 0.078
  外推 ADE: 0.428
  退化倍数: 5.5× → CQ = -4.483
```

纯 SIREN 在 (位置 → 颜色) 目标下不学习因果结构——它学的是像素间的统计相关。当速度分布偏移时，相关关系立即崩塌。

> **方法论意义**: 纯神经场 = 纯相关。因果外推需要 L4 的显式因果约束——这直接支撑公理 1（因果优先）和公理 4（预测最小化→需因果方向约束）。

#### 发现 3: SIREN 的 µP 不缩放 (E2.1d)

```
hidden=64:  17K params, PSNR=33.3dB (50 epochs)
hidden=128: 67K params, PSNR=33.3dB (50 epochs)
参数翻 4 倍 → PSNR 零提升
```

µP 是为 Transformer 设计的缩放律——正弦激活 SIREN 的瓶颈不在模型容量，在空间采样密度（64 rays/view）和训练信号量。

> **方法论意义**: L3 的 scaling law 不是参数计数，是空间分辨率。这对工程路线图有直接影响——优先升级分辨率，而非加宽网络。

## 一、出发点：为什么需要心智层级？

### 1.1 LLM 范式的认知天花板 [Causality for LLMs 2024; Parrot 2024]

当前主流范式——自回归语言建模 + RLHF——在以下维度遇到根本性困难：

- **统计关联 vs 因果推理** [Kıcıman 2023, Parrot 2024]: 语言模型学的是条件分布 P(token|context)，而非干预分布 P(effect|do(cause))
- **表面流畅 vs 深层理解**: Chinchilla 定律指向数据规模，但规模增长不自然产生理解
- **单一尺度 vs 多尺度认知**: 一个 transformer 同时处理句法和逻辑——没有层级分化
- **离线训练 vs 在线适应**: 权重冻结，无法在运行中重新组织认知资源
- **因果鹦鹉现象** [Parrot 2024]: LLM 背诵因果知识而不真正理解——prompt 激活语料关联而非因果推理

**M0 实验印证**: E2.3 在纯感知层面（无语言）复现了同一种模式——SIREN 能拟合训练速度下的运动模式，但分布一外推立即崩塌（5.5×退化）。这说明"学相关而不学因果"是通用学习系统的深层倾向，不限于语言模型。

### 1.2 心智层级的必要性论证

来自认知科学的三股证据汇聚:

| 来源 | 发现 | 含义 |
|------|------|------|
| 发展心理学 (Piaget, Vygotsky) | 认知能力不可跳跃的顺序发育 | 层级之间有严格的前置依赖 |
| 神经科学 (Mesulam hierarchy, Friston free energy) | 皮层呈现清晰的层级梯度 | 层级是大脑的组织原则 |
| 认知架构 AI (SOAR/ACT-R/Sigma) [Common Model of Cognition] | 符号心智操作需要多模块协同 | 50+ 年的认知 AI 已验证层级必要 |
| **M0 实验 (新增)** | SIREN 无法同时学渲染+分类 (E2.1c) | 多任务需要在层级间分工，不可扁平成单一网络 |

**推论**: 心智层级不是设计选择，是**认知公理的必要结构**。

## 二、五层心智模型

```
Layer 5: 元认知层 ── 自我模型、全局工作空间、策略选择 [GWT 1988; GLW 2024; MIDCA 2022]
    ↑ 监控(META_MONITOR)、评估(META_EVAL)、重定向(META_OVERRIDE)
Layer 4: 因果推理层 ── 因果推断、反事实思维、数学推演 [VCI 2024; NCM 2022; Abs-LiNGAM 2024]
    ↑ 因果紧缩、关系绑定、符号抽象
Layer 3: 世界模型层 ── 连续神经场表征、物理直觉、预测编码 [NF-as-WM 2026; VJEPA 2024]
    ↑ 多模态融合、动力学建模、对象分割
Layer 2: 感知-行动层 ── 模式识别、运动控制、主动推理 [Deep AIF 2017; MC AIF 2020]
    ↑ 特征提取、闭环控制、传出副本
Layer 1: 信号层 ── 原始感官编码、时序对齐、跨模态配准
```

### 2.1 Layer 1: 信号层

**功能**: 原始输入的时序编码与跨模态对齐

**数学框架**: 
- 时序编码: 具有因果约束的变分自编码器
- 跨模态对齐: 对比学习的拓扑约束版本——不仅对齐实例，更保持模态间的拓扑关系
- 采样/压缩权衡: 遵循 rate-distortion 理论的适应率版本

**关键约束**: 本层不执行语义解释——只有信号保真度。语义是上层添加的。

### 2.2 Layer 2: 感知-行动层

**功能**: 从信号中提取不变特征，形成感知-行动闭环

**数学框架** [Deep AIF 2017; MC AIF 2020]:
- 不变表征学习: 寻找群作用下的不变量
- 主动感知: 行动是感知的组成部分——遵循 Friston 变分自由能 (VFE) 框架
- 注意力: 基于预期信息增益 (EIG) 的信息论注意力——超出 transformer token attention

**传出副本 (可选)** [Action-Unaware 2025]: L3 的运动门控通道可接入传出副本——agent 直接知道自己的动作以简化推理。

**关键接口** (L2 → L3): 输出"感知状态向量"——包含当前场景的压缩表征 + 估计的不确定性 + 注意焦点

### 2.3 Layer 3: 世界模型层 ⭐ 核心

**功能**: 构建对世界状态的连续、动态、可预测的内部模型

> **世界模型公理**: 任何在物理世界中行动的系统，其智能上限受制于其内部世界模型的分辨率和保真度。

**🎯 独立验证** [Neural Fields as World Models 2026, arXiv:2602.18690]:
> 该文献独立推演出与白皮书相同的结论——神经场在物理预测中自然保持空间拓扑结构。这是本框架在当前文献中的**最强外部验证**。

**🏗️ M0 实验验证 (新增)**:

E2.1a/b 证明 SIREN 可以高质量渲染单/多物体场景（36.6dB/30.6dB）。基础能力通过。

E2.1d 发现：SIREN 的 PSNR 不随参数缩放（hidden 64→128, PSNR=33.3dB 不变）。L3 的 scaling law = 空间采样密度，非参数计数。

E2.1c 发现：**SIREN 无法隐式学习物体分解**。这不是工程问题——体渲染的射线加权累积在数学上丢失逐点身份信息。物体分解需要升至 L4 的离散符号空间。

**数学框架 — 神经场世界模型**:

```
Φ: ℝ³ × ℝ → ℝᵈ
Φ(x, t) = (geometry, semantics, affordance, uncertainty)
```

**对象场** [OBAI 2022]: φ_k(x,t) 为每个对象分配独立神经场——选择性注意力路由输入到对应槽。

> **M0 教训**: 标准 NeRF 训练下，即使引入 slot attention，也需 point-level 解耦。ray-level 的渲染输出天然混合所有物体。

**预测编码实现** [PCN 2018; µPC 2025; Hybrid PC 2022]:
- 前馈传递误差↑ + 反馈传递预测↓ + 递归循环到收敛 [PCN 2018]
- µPC 参数化使 100+ 层 PCN 稳定训练 [µPC 2025 PhD] — PC 学习 = 隐式二阶信任域
- 混合推理: 熟悉输入上快速摊销 → 异常输入上切换迭代 [Hybrid PC 2022]

**预训练策略** [VJEPA 2024; Causal-JEPA 2026]:
- VJEPA: 预测编码 = 信息论最优的视频表征学习
- Causal-JEPA: 从对象级遮掩中涌现因果方向——**因果可内建于 L3 训练目标**

### 2.4 Layer 4: 因果推理层

**功能**: 基于 L3 神经场提供的状态表征，执行结构因果操作

**数学框架**:

- **因果引擎** [VCI 2024; NCM 2022]:
  - 基于 Pearl SCM，从 L3 的连续表征中学习因果图
  - do-calculus、反事实查询、中介分析
  - VCI (2024-10): **端到端反事实训练——无任何反事实样本; CVAE 不适合因果推断**

- **因果发现** [ILS-CSL 2023; Abs-LiNGAM 2024]:
  - 因果图从 L3 神经场的运行中**自动发现**，非手工标注
  - 分层策略: 高层模型 (快速) → 约束 → 底层大模型恢复 (Abs-LiNGAM)
  - LLM 先验: 迭代精炼的因果约束 [ILS-CSL]——LLM 是加速器，不是引擎 [Parrot 2024]

- **因果抽象** [Abstracting Causal Models 2018]:
  - L3(连续场) → 抽象函数 A → L4(离散因果图)
  - 四层严格度递增的抽象定义——"概念紧缩"在数学上 = 因果抽象

> **M0 印证 (E2.3)**: 纯 L3 SIREN 在多速度外推上崩 5.5×。这直接证明 L3 需要来自 L4 的因果约束——抽象的因果方向必须从离散因果图回灌到连续神经场。

**关键接口** (L4 → L5): 输出"置信度赋值的推理链"——包含推理步骤 + 每一步的置信度 + 关键假设列表

### 2.5 Layer 5: 元认知层

**功能**: 监控、评估、重新配置下层操作——认知的"操作系统内核"

**理论根基**:

| 来源 | 贡献 | 引用 |
|------|------|------|
| Wise Machines | 四大故障 → 元认知缺失是共同根因 | 2024 |
| GWT | 全局工作空间 = 信息整合与广播 | 1988 |
| Global Latent Workspace | 首个 ML 原型: 中央潜在表征 + 编解码桥 | 2024 |
| MIDCA | 声明式认知轨迹追踪 + 元级目标操作 | 2022 |
| meta-d' | AI 元认知敏感度的量化框架 | 2026-03 |

**核心操作**:
- **全局态 G(t)**: 中央潜在表征——实时整合所有层的压缩状态 [GWT; GLW]
- **置信度校准**: meta-d' 度量框架——将推理置信度与真实准确率对齐
- **快/慢切换**: 利用预测误差自动驱动——低误差快通道、高误差慢通道 [Hybrid PC]
- **资源分配**: 计算预算的认知经济学——在哪些问题上花时间?
- **自我模型** [MIDCA 2022]: 自身能力的精准边界——认知诚实，不是对齐顺从
- **可纠错性**: 不知道时拒绝行动——校正优先

> **M0 启示**: E2.3 的外推崩溃（5.5×）本可由 L5 监控捕获——若预测误差超过阈值，自动触发深度因果推理解锁，而非继续使用快通道的统计预测。这正是快/慢切换设计的目的。

## 三、认知公理体系（十条）— 附文献+M0 双重验证

### 公理 1: 因果优先

**陈述**: 智能以干预（do）而非被动观察为基本认知操作

**不变式**: ∀ 推理步骤 s, 存在因果图 G_s s.t. P(effect | context) ≠ P(effect | do(cause))

**文献支撑**:
- Causal Neurosymbolic AI (2024-05): 因果显式编码入 NeSy 系统
- VCI (2024-10): CVAE 不适合反事实——需要专门的因果推断框架
- Causal-JEPA (2026-02): 因果方向可从对象级遮掩中涌现
- NCM (2022): 神经网络可直接学习结构方程

**🟡 M0 实验支撑 (E2.3)**:
- 纯 SIREN (仅 L3) 在多速度外推上崩 5.5× → 被动观察学到的统计相关不支撑 OOD 因果推断
- 验证了公理的核心否定性预测: "没有因果约束的系统必然在分布偏移上失败"

### 公理 2: 层级依赖

**陈述**: 上层能力严格依赖于下层提供的表征质量，不可跳跃

**不变式**: ∀ 层 L_i, 其操作的有效性 ≤ min( 下层 L_{i-1} 表征质量, 本层算法能力 )

**文献支撑**:
- Common Model of Cognition: SOAR/ACT-R/Sigma 的模块层级 50+ 年实验验证
- MIDCA (2022): 元认知层通过监控层间消息发挥作用——层间不可扁平化
- Hierarchical Meta-Learning (2019): 层级元学习在各层有不同的最优策略

**🟡 M0 实验支撑 (E2.1c)**:
- SIREN 无法同时优化渲染损失 + 分类损失 → 共享骨干下二任务梯度冲突 (v3: PSNR 25.9dB 卡死)
- 物体分解 (L4 级别任务) 强压在 L3 单一 SIREN 上 → 本质失败
- **验证了层级不可扁平化**: 不同抽象级别的任务需要不同层级的架构

### 公理 3: 压缩保真

**陈述**: 认知必须压缩信息（rate），但压缩损失了哪些信息必须显式维护（distortion budget）

**不变式**: ∀ 认知周期, 存在显式的 distortion_budget, 且 L5 维护 total_distortion = Σ distortion_i

**文献支撑**:
- Rao-Ballard 协议 (1999→2020): 层的输出 = 仅压缩后的误差——信息经济性
- Generalised PC (2021): 精度加权 = 不确定性跟踪——决定了信息是否被降权
- Hybrid PC (2022): 误差驱动的模式切换——压缩失败时切换到迭代推理

### 公理 4: 预测最小化

**陈述**: 学习驱动信号 = 最小化预测误差（广义自由能）

**不变式**: 任意层的权重更新 ΔW_i ∝ −∂ℱ/∂W_i, ℱ = Σ ε_j · precision_j

**文献支撑**:
- Deep AIF (2017): VFE 统一感知、行动、学习——奠基性实验
- µPC (2025 PhD): PC = 隐式二阶信任域——100+ 层可训练
- VJEPA (2024): 预测编码 = 视频表征学习的信息论最优方案

**🟡 M0 实验支撑 (E2.3)**:
- SIREN 在训练速度上预测误差低 (内插 ADE=0.078) → 统计学习成功
- 外推速度上预测误差飙升 (ADE=0.428) → 统计学习不等于因果理解
- **验证了预测最小化的局限**: 仅最小化观测误差不足——需要因果方向的误差分解

### 公理 5: 不确定性守恒

**陈述**: 任何推理步骤引入的不确定性必须追踪、传播、不可丢弃

**不变式**: ∀ 推理链 R = [s_1, ..., s_n], 总不确定性 U(R) ≥ max(U(s_i)), 且 U(s_i) 被显式追踪

**文献支撑**:
- meta-d' 框架 (2026-03): AI 元认知敏感度的度量化——三个量化轴的实验
- MC AIF (2020): MC Dropout 预测未来参数信念更新——不确定性的时序传播
- VCI (2024): 外生噪声外溯——不确定性的因果追踪

### 公理 6: 组合完备

**陈述**: 有限原语的无限合法组合必须在表征空间中可表示

**不变式**: ∀ 合法组合 c = compose(a_1, ..., a_k), ∃ 表征 r(c) ∈ R, 且 parse(r(c)) ≈ [a_1, ..., a_k]

**文献支撑**:
- Gardenfors Conceptual Spaces (2000): 概念 = 凸区域——组合 = 区域的并/交/投影
- LNN vs LLM-SS (2025-08): 混合式的组合泛化 > 整合式
- Formalized Conceptual Spaces (2018): 模糊星形集修正——相关性的几何映射

**🟡 M0 实验支撑 (E2.1c 侧面)**: 背景 (0,1,0) + 三个球 → SIREN 无法学习场景组成——物体组合只在 L4 不同token/符号层级可表示。

### 公理 7: 时间因果

**陈述**: 因果推理和预测必须尊重光锥约束——未来信息不能泄露到过去预测中

**不变式**: ∀ 时间 t, 预测 P_t 仅依赖于信息 I_{≤t}, 且 |P_t − future|<|prior − future|

**文献支撑**:
- Causal-JEPA (2026-02): 对象级遮掩确保因果方向的时间正确性
- VCI (2024): do-calculus 的三阶段推理——每一阶段的时间约束不同
- Causal Gen. Survey (2023): 可识别因果表征 → 时间约束是识别性的必要条件

### 公理 8: 资源有限

**陈述**: 认知资源是有限的——智能是约束优化

**不变式**: 认知操作受 compute_budget 约束，系统在此预算下最大化 E[task_success]

**文献支撑**:
- Hybrid PC (2022): 快/慢推理 = 计算预算的认知经济学
- MIDCA (2022): 元认知 = 选择性监控——不监控全状态，监控关键轨迹
- Dynamic Early Exiting PCN (2023): 推理提前退出——耗尽预算时终止

### 公理 9: 自指安全

**陈述**: 自我模型的精度必须高于世界模型的精度

**不变式**: accuracy(self_model) ≥ accuracy(world_model) + Δ, Δ > 0 为安全边际

**文献支撑**:
- Wise Machines (2024): 智慧 > 对齐——自我认知是安全的先决条件
- Global Latent Workspace (2024): 自模型从感官-运动桥接中自然涌现
- Metacognition Review (2025): 元认知的三阶段——自我规划 → 自我监控 → 自我评价

### 公理 10: 伦理前置

**陈述**: 安全约束嵌入所有层级，而不是顶层事后添加

**不变式**: 每个层级 L_i 存在安全约束 C_i, 违反约束的操作被 L_i 自身拒绝（而非上层事后纠正）

**文献支撑**:
- Wise Machines (2024): 把 AI 的不安全归因于元认知缺陷——安全嵌入认知架构
- A Case for AI Consciousness (2024-10): GWT→AI 的充要条件方法论——伦理前置在架构
- Causality for LLMs (2024-10): 六个未来方向——伦理前置是其中一个核心

## 四、层级间协议 v1.0

### 4.1 消息格式 [RB 1999→2020; Generalised PC 2021; Hybrid PC 2022]

```
消息 = {type, layer_from, layer_to, payload, precision, trace}

type ∈ {PRED↓, ERROR↑, QUERY⇅, RESULT⇅, META_OVERRIDE↓, PRIOR↓, GLOBAL⇄, BEACON⇅}

PRED↓: 高层→低层的先验预测
  payload: {content_prediction, dynamics_prediction}
  precision: ℝ⁺⁺ (来自该层的置信度得分)

ERROR↑: 低层→高层的预测误差
  payload: {content_error, dynamics_error}
  precision: ℝ⁺⁺ (误差的逆精度——噪声大→低权)
  不变式: error = actual − predicted

GLOBAL⇄: L5 广播的全局态内容
  payload: 所有层压缩状态的整合
  频率: 每个认知周期 (~50ms) [SOAR/ACT-R period]

PRIOR↓: L4→L3 的因果约束先验
  payload: 当前因果图中的结构约束

META_OVERRIDE↓: L5→任意层的紧急配置
  权限: 仅 L5 可发送
  安全: 需包含 trace = 触发此重配置的认知溯源
```

### 4.2 经济性担保

```
在任何认知周期中:
若 |ε_i| < threshold → L_i 不上传消息
若 |ε_i| ≥ threshold → L_i 上传 {ERROR↑, ε_i, precision_i}

在稳态/熟悉场景中: 大部分层几乎无信号流动 → 总通信 ~ O(1)
在异常/新场景中: 信号流动 ~ O(n_layers × n_active_modules)
```

### 4.3 模式切换 [Hybrid PC 2022]

```
predictive_error ← |actual − predicted|

if predictive_error < τ:
  inference_mode ← AMORTIZED (前馈快通道)
  learning ← OFF
else:
  inference_mode ← ITERATIVE (递归慢通道)
  learning ← ON (仅对异常部分更新权重)
```

> **M0 校准 (E2.3)**: inner ADE=0.078 vs outer ADE=0.428。τ 可设在此之间: 当预测误差 > τ_switch, L5 切断 L3 的快通道输出, 强制路由至 L4 因果推理。

### 4.4 层级拓扑 — 非线性图结构 [Generalised PC 2021 open]

每一层内部可以有多个子模块——子模块间通过 Markov Blanket 交换信息。L5 维护一个动态的"认知模块活跃图"——哪些子模块正在处理什么，当前的计算瓶颈在哪里。

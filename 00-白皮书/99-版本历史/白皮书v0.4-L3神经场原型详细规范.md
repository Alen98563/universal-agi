## 摘要

v0.4 是 L3 神经场世界模型从概念设计到工程规格的转折版本。核心变化：M0 六项实验的三条方法论发现被转化为**硬设计约束**，而非参考意见。本规范定义了一个 M0 后修正的神经场架构，整合 SIREN 渲染、点级槽注意力、Transformer 动力学预测器、µPC 训练框架，并预设了 L4 因果约束的注入接口。

## 一、M0 驱动设计原则

### 1.1 从实验发现到设计约束

| M0 发现 | 推导的设计约束 | 约束类型 |
|---------|---------------|----------|
| **E2.1c**: SIREN 无法隐式学物体分解 (ARI=0, 8版本) | [C1] 物体分解必须使用**点级**分类（采样点 → logits），禁止 ray 级渲染输出分类 | 架构硬约束 |
| **E2.1c**: 体积渲染混合逐点身份信息 | [C2] 槽注意力的 query 必须在 point-level，分类必须在 volume_render 之前完成 | 架构硬约束 |
| **E2.1d**: µP 对 SIREN 不缩放 (4×参数→0 PSNR) | [C3] L3 scaling law = 空间采样密度主导，非参数计数。优先提升分辨率→射线数→再考虑加宽 | 资源分配 |
| **E2.1d**: 训练瓶颈在采样数而非模型容量 | [C4] 训练配置: rays_per_batch >> hidden_dim。每个场景至少 512 rays，n_views ≥ 3 | 训练配置 |
| **E2.3**: 因果外推崩溃 5.5× (CQ=-4.48) | [C5] L3 输出必须附带预测不确定性 → L5 用此决定快/慢通道切换。τ_switch 参考 ADE_inner vs ADE_outer 间隙 | 接口约束 |
| **E2.3**: 纯预测不产生因果理解 | [C6] L3 的输出格式必须包含可供 L4 消费的"结构化状态"（非仅像素），以支撑因果发现 | 接口约束 |
| **E2.1a/b**: SIREN 单/多球渲染高质量 (36.6/30.6dB) | [C7] 基础 SIREN 渲染保持为骨干。4×256，ω₀=30, 5层。通过 M0 验证的配置不做无谓变更 | 性能基线 |

### 1.2 约束优先级与冲突解决

```
约束冲突时的优先级:
  C2 (point-level identity) > C1 (classification before render) > C7 (SIREN backbone)
  C5 (uncertainty for switch) > C6 (structured state for L4)
  C3 (resolution first) > C4 (rays first)

含义: 如果需牺牲渲染质量来保证物体分解正确性 → 牺牲渲染质量。
      L3 的根本任务是"为 L4 提供可操作的连续状态"，不是"渲染好看"。
```

### 3.1 神经场骨干: SIREN Field

```
模块名: SIRENField
文件: src/models/neural_field.py
关键类: SIRENLayer, SIREN

规格:
  in_features: 3 (x,y,z)

  [36:44]  affordance:  graspable, pushable, stable, movable, ... (8-dim)
  [44:46]  uncertainty: aleatoric, epistemic (2-dim)

  - 第一层: uniform(-1/3, 1/3)

  - 4层而非5层: M0 发现 5×256 的 PSNR 与 4×256 无差别 (E2.1d)
  - 节省 ~20% 参数量, 训练更快
```

### 3.2 点级分类器: PointClassifier [C1][C2]

```
模块名: PointClassifier
文件: src/models/point_classifier.py

这个模块是 M0 最关键的修正——将分类从 ray 级渲染后移到 point 级采样点。

核心原则:
  - 对每条射线的每个采样点 (x_n, t), 在 volume_render 之前做分类
  - 分类损失作用于所有采样点 (不是渲染后的像素)
  - ARI 评估: 取每条射线上权重最大采样点的分类 = 该像素的预测标签

class PointClassifier(nn.Module):
    def __init__(self, shared_dim: int = 256, num_slots: int = 5):
        super().__init__()
        self.classifier = nn.Sequential(
            nn.Linear(shared_dim, 128),
            nn.ReLU(),
            nn.Linear(128, num_slots)
        )
        # 输出的 logits 对应 num_slots 个对象槽 + 1 个背景
    
    def forward(self, z_shared: Tensor) -> Tensor:
        """
        Args:
            z_shared: [B, N_rays, N_samples, 256]
                      从 SIREN backbone 提取的逐点特征
        Returns:
            slot_logits: [B, N_rays, N_samples, K]
                        每个采样点属于每个槽的 logit
        """
        return self.classifier(z_shared)

    def classification_loss(
        self, slot_logits: Tensor, gt_labels: Tensor, weights: Tensor
    ) -> Tensor:
        """
        在每个采样点上计算交叉熵损失

        Args:
            slot_logits: [B, N_rays, N_samples, K]
            gt_labels:   [B, N_rays, N_samples] 逐点 GT 标签 (包含 -1 = 背景)
            weights:     [B, N_rays, N_samples] 体积渲染权重 (alpha * T)

        Returns:
            loss: scalar — 按权重加权的 CE 损失
        """
        valid = gt_labels >= 0  # 忽略背景和遮挡点
        if valid.sum() == 0:
            return torch.tensor(0.0)

        # 仅对有效点计算 CE, 按体积渲染权重加权
        logits_valid = slot_logits[valid]  # [N_valid, K]
        labels_valid = gt_labels[valid].long()
        w_valid = weights[valid]

        ce = F.cross_entropy(logits_valid, labels_valid, reduction='none')
        return (ce * w_valid).sum() / (w_valid.sum() + 1e-8)

ARI 评估流程:
  1. 对每条射线, 找到权重最大的采样点索引: i* = argmax(weights)
  2. 该点的预测: pred_label = argmax(slot_logits[i*])
  3. 背景像素 (GT=-1): 跳过, 不参与 ARI 计算
  4. 只对球像素 (GT∈{0,1,2}) 计算 ARI

class_weights:
  - 标准训练中球像素占比 ~1.5% (64×64分辨率下)
  - 需要 class_weight 或 focal loss 对抗类别不平衡
  - 推荐: focal_loss(gamma=2.0) + 背景权重=0.1
```

### 3.3 槽注意力: SlotAttention (OBAI) [C2修正]

```
模块名: SlotAttention
文件: src/models/object_slot.py

M0 修正:
  - 原设计文档在 ray 级做注意力 → E2.1c 证明不可行
  - v0.4: 注意力在 point 级执行

class SlotAttention(nn.Module):
    def __init__(self, num_slots: int = 5, slot_dim: int = 128,
                 feature_dim: int = 256, num_iterations: int = 3):
        super().__init__()
        self.num_slots = num_slots
        self.slot_dim = slot_dim
        self.num_iterations = num_iterations

        # 可学习槽向量
        self.slots_mu = nn.Parameter(torch.randn(1, num_slots, slot_dim) * 0.02)
        self.slots_log_sigma = nn.Parameter(torch.zeros(1, num_slots, slot_dim))

        # 注意力投影
        self.q_proj = nn.Linear(slot_dim, slot_dim, bias=False)
        self.k_proj = nn.Linear(feature_dim, slot_dim, bias=False)
        self.v_proj = nn.Linear(feature_dim, slot_dim, bias=False)

        # GRU + MLP 更新
        self.gru = nn.GRUCell(slot_dim, slot_dim)
        self.mlp = nn.Sequential(
            nn.Linear(slot_dim, slot_dim * 2), nn.ReLU(),
            nn.Linear(slot_dim * 2, slot_dim)
        )
        self.norm = nn.LayerNorm(slot_dim)

        # 槽置换不变性: 不同初始噪声 → 相同语义分配
        # 验证: 运行 10 次不同随机种子, ARI 方差 < 0.01

    def forward(self, features: Tensor) -> Tuple[Tensor, Tensor]:
        """
        Args:
            features: [B, N, D] shared field features at each sampled POINT
        
        Returns:
            slots: [B, K, slot_dim] updated slots
            attention: [B, K, N] attention distribution (permutation invariant)
        """
        B, N, D = features.shape
        K = self.num_slots

        # 初始槽 (带噪声 → 置换不变性)
        mu = self.slots_mu.expand(B, -1, -1)
        sigma = self.slots_log_sigma.exp().expand(B, -1, -1)
        slots = mu + sigma * torch.randn_like(sigma)

        # 迭代注意力 (point-level, not ray-level!)
        for _ in range(self.num_iterations):
            slots_prev = slots
            q = self.q_proj(self.norm(slots))   # [B, K, D_q]
            k = self.k_proj(features)           # [B, N, D_k]
            attn_logits = torch.einsum("bkd,bnd->bkn", q, k)
            attn_logits = attn_logits / math.sqrt(self.slot_dim)
            attn = F.softmax(attn_logits, dim=1)

            v = self.v_proj(features)
            updates = torch.einsum("bkn,bnd->bkd", attn, v)

            slots = self.gru(
                updates.reshape(B * K, self.slot_dim),
                slots.reshape(B * K, self.slot_dim)
            ).reshape(B, K, self.slot_dim)

            slots = slots + self.mlp(self.norm(slots))

        return slots, attn
```

### 3.4 对象场: ObjectField

```
模块名: ObjectField
文件: src/models/neural_field.py::MultiObjectNeuralField

每个槽 k 拥有独立的轻量级 SIREN:

  Φ(x,t) = Σ_k α_k(x) · φ_k(x,t)
  
  α_k(x) 来自槽注意力或点级分类器 (取决于训练阶段)
  初期: 使用点级分类器 logits → softmax
  后期: 使用槽注意力 attention weights
```

### 3.5 体积渲染器: VolumeRenderer

```
模块名: VolumeRenderer
文件: src/models/volume_render.py

标准 NeRF 体积渲染:
  - 射线采样: near=2.0, far=6.0, n_samples=64 (分层+扰动)
```

### 3.6 动力学预测器: DynamicsPredictor

```
模块名: DynamicsPredictor
文件: src/models/dynamics.py

z_k^t = encode(φ_k(·, t))      # 每个对象场的 latent token
z_k^{t+Δt} = Transformer(z_1^t, ..., z_K^t)

class DynamicsPredictor(nn.Module):
    def __init__(self, d_latent: int = 128, n_layers: int = 2, n_heads: int = 8):
        self.tokenizer = nn.Linear(46, d_latent)       # φ→token
        self.transformer = nn.TransformerEncoder(
            encoder_layer=nn.TransformerEncoderLayer(
                d_model=d_latent, nhead=n_heads, 
                dim_feedforward=d_latent*2, dropout=0.1,
                batch_first=True
            ),
            num_layers=n_layers
        )
        self.decoder = nn.Linear(d_latent, 46)          # token→φ_next

    def forward(self, z: Tensor) -> Tensor:
        """
        z: [B, K, 46] — K slots' current state
        returns: [B, K, 46] — K slots' predicted next state
        """
        tokens = self.tokenizer(z)         # [B, K, 128]
        tokens_next = self.transformer(tokens)
        return self.decoder(tokens_next)

动力学损失:
  L_dyn_1step = MSE(z_k^{t+1}_pred, z_k^{t+1}_gt)      # 1步预测
  L_dyn_4step = MSE(z_k^{t+4}_pred, z_k^{t+4}_gt)      # 4步 rollout
  L_collision = BCE(collision_pred, collision_gt)       # 碰撞预测

训练策略:
  - 初期: 仅 L_dyn_1step (稳定)
  - 中期: 加入 L_dyn_4step (长程)
  - MVE: 加入 L_collision (因果 Pong)
```

### 3.7 因果先验注入接口: CausalInjection [C5][C6]

```
模块名: CausalInjection
文件: src/causal/injection.py

这是 L4 → L3 的 PRIOR↓ 摄入点——未来 L4 因果图回灌的接口。

class CausalInjection(nn.Module):
    def __init__(self):
        # 因果约束编码器
        # 输入: L4 的因果图约束 (边, 方向, 强度)
        # 输出: attention mask modifier
        
    def apply_causal_mask(
        self, attention_weights: Tensor, causal_constraints: Dict
    ) -> Tensor:
        """
        将 L4 的因果约束应用于动力学预测器的 attention mask
        
        causal_constraints 示例:
        {
            "edges": [(A, B, "causes")],  # 边列表
            "forbidden": [(B, A)],         # 禁止方向
            "strength": {(A, B): 0.8},    # 因果强度
            "lag": {(A, B): 2}            # 因果延迟 (steps)
        }
        
        返回: 修改后的 attention_weights (masked)
        """

E2.3 启示:
  纯 L3 动力学预测学的是"概率转移矩阵 P(z_B | z_A)"
  而不是"干预关系 P(z_B | do(z_A))"
  
  L4 注入的因果约束告诉 L3: 
    "z_A 的某些变化会导致 z_B 变化"
    → 动力学预测器在这些维度上分配更多注意力
    → 在 OOD 场景中不盲目依赖统计相关
```

### 3.8 预测编码训练框架: PCN µPC

```
模块名: PCNTrainer
文件: src/models/predictive_coding.py

class PCNTrainer:
    """
    多层预测编码训练，使用 µPC 参数化
    """

    def __init__(self, layers: List[nn.Module]):
        self.layers = layers
        self.n_iterations = 5  # PC 推理迭代次数
        
    def train_step(self, batch: Tuple) -> float:
        # 1. 前馈 (bottom-up ERROR↑)
        h = batch.x
        activations = [h]
        errors = []
        
        for layer in self.layers:
            pred = layer.predict(activations[-1])
            actual = layer.encode(batch.current)
            error = actual - pred
            errors.append(error)
            h = layer.forward(h)
            activations.append(h)
        
        # 2. 反馈 (top-down PRED↓)
        for i in range(len(self.layers)-1, -1, -1):
            pred_topdown = self.layers[i].decode_from_above(activations[i+1])
            self.layers[i].update_prior(pred_topdown)
        
        # 3. 自由能 (A4)
        F = 0
        for e, layer in zip(errors, self.layers):
            precision = layer.compute_precision()
            F += precision * (e ** 2).sum()
        
        # 4. µPC 参数化更新
        # η/sqrt(fan_in) 保证极限宽度稳定训练
        F.backward()
        for p in self.parameters():
            fan_in = p.shape[1] if p.dim() >= 2 else 1
            p.grad *= lr / math.sqrt(fan_in)
        
        return F.item()

关键: µPC 参数化让多层共享 lr，无需逐层调参
      E2.1d 证实 SIREN 不缩放的根因不在 PC/µP，
      而是训练信号量（采样密度）主导 PSNR
```

## 四、训练方案

### 4.1 三阶段训练

```
Phase 1 — 感知预训练 (单场景静态)
  目标: 学会从任意视角渲染 3D 场景
  模型: SIRENField (共享骨干 + 渲染)
  数据: 单场景 × 50 随机相机视角 (半球面采样)
  损失: L_photo (纯 MSE RGB)
  规模: ~10³ scenes, ~5×10^5 steps
  验收: PSNR > 30dB (多物体), PSNR > 35dB (单物体)
  M0 参考: E2.1a (36.6dB), E2.1b (30.6dB) ✓

Phase 2 — 物体分解 + 动力学
  目标: 在已训练的场上学物体分割 + 时序预测
  模型: + PointClassifier + ObjectField + DynamicsPredictor
  数据: 多物体渲染视图 (每个场景 n_views ≥ 3, [C4])
        物理交互序列 (MuJoCo 推/抓/放)
  损失: L_photo + L_classification (focal, gamma=2) + L_dyn_1step
  训练细节:
    - 冻结 SIRENField 几何头部 ([C7] 保留已验证渲染能力])
    - 仅训练分类头 + 对象场 + 动力学
    - 类别权: 球类 × 20 vs 背景 × 0.1 (对抗 1.5% 球像素)
  验收: ARI > 0.5 (初步分割), 1-step MSE < baseline
  注意: M0 中 ARI=0 的根因已通过 [C1][C2] 解决，
        预计 Phase 2 的 ARI 可达非零值
        
Phase 3 — 因果约束 + 泛化
  目标: 动力学预测中加入因果方向约束, 跨场景泛化
  模型: + CausalInjection + Meta-learning outer loop
  数据: 因果 Pong (标准 + 遮挡 + 反事实变体)
  损失: L_photo + L_classification + L_dyn_4step + L_collision + L_causal
  训练细节:
    - Causal-JEPA 遮掩: 掩掉对象A的未来帧 → 迫使模型从B推断A
    - L_causal: 推断因果方向 vs ground truth Jaccard
  验收: Causal Direction > 0.7, Counterfactual Accuracy > 0.5

MVE — 因果 Pong 终极测试
  场景: 两个球弹性碰撞, 多种速度, 多种初始位置
  对比基线: DreamerV3, V-JEPA
  预期: L3 PCN > DreamerV3 at 1/4/16-step rollout
        特别是在 Hidden + Counterfactual 变体上拉开差距
```

## 五、消息协议集成

### 5.1 L3 消息流

```
L3 接收的消息:
  ┌─────────────────┬───────────────┬────────────────────────┐
  │ 来源             │ 类型          │ payload                 │
  ├─────────────────┼───────────────┼────────────────────────┤
  │ L2 → L3         │ ERROR↑        │ 感知误差 + 注意焦点     │
  │ L4 → L3         │ PRIOR↓        │ 因果图约束 [C6]         │
  │ L4 → L3         │ PRED↓         │ 高层预测 (概念)         │
  │ L5 → L3         │ META_OVERRIDE↓│ 模式切换/重配置         │
  │ L5 → L3         │ GLOBAL⇄       │ 全局态势 G(t)           │
  └─────────────────┴───────────────┴────────────────────────┘

L3 发送的消息:
  ┌─────────────────┬───────────────┬────────────────────────┐
  │ 目标             │ 类型          │ payload                 │
  ├─────────────────┼───────────────┼────────────────────────┤
  │ L3 → L4         │ ERROR↑        │ 结构化状态 + 不确定性   │
  │                 │               │ + 几何 + 语义 [C5][C6] │
  │ L3 → L2         │ PRED↓         │ 内容预测 + 动力学先验   │
  │ L3 → L5         │ BEACON⇅       │ 模块心跳 + 资源状态     │
  └─────────────────┴───────────────┴────────────────────────┘

消息经济性 (正常模式):
  熟悉场景: L3 不上传 ERROR↑ (预测误差 < τ)
  → 仅下游 BEACON⇅ + 响应 L5 GLOBAL⇄
  → 计算 ~2ms, 通信 ~O(1)

消息激活性 (异常模式):
  新场景: L3 上传 ERROR↑ → L4 请求因果推理
  → 同时接收 PRIOR↓ 因果约束回灌
  → 计算 ~25ms, 通信 ~O(K + 1)
```

### 5.2 快/慢切换阈值校准 [C5]

```
基于 E2.3 实验数据:
  ADE_inner = 0.078  (训练速度集上的预测误差)
  ADE_outer = 0.428  (外推速度集上的预测误差)
  比值: 5.5×

推荐 τ_switch 区间:
  τ_low  = 1.5 × ADE_inner = 0.117
  τ_high = 0.4 × ADE_outer = 0.171

切换逻辑:
  if L3.predictive_error < τ_low:
    → AMORTIZED mode (快通道, 前馈)
  elif L3.predictive_error > τ_high:
    → ITERATIVE mode (慢通道, 递归推理)
    → L3 requests PRIOR↓ from L4
    → L4 performs causal reasoning
  else:  # in hysteresis zone
    → keep current mode (避免振荡)

具体实现:
  τ_switch = 0.15 (可通过校准实验精调)
  hysteresis_margin = 0.02
```

## 八、方法与教训 (M0 传承)

### 8.1 不做什么

1. **不在 ray-level 做分类** — E2.1c 充分证明体渲染的射线加权湮灭逐点身份
2. **不盲目加参数** — E2.1d 证明 SIREN 的 PSNR 瓶颈在分辨率, 不在 hidden dim
3. **不期望纯预测通往因果** — E2.3 证明统计相关 ≠ 因果理解, 需要 CausalInjection
4. **不用 64×64** — 球像素仅占 1.5%, MSE 99% driven by background
5. **不单视角训练** — n_views=1 导致过拟合视角而非学 3D

### 8.2 白皮书公理在 v0.4 中的体现

| 公理 | v0.4 体现 |
|------|----------|
| A1 因果优先 | CausalInjection 预留接口 [C6], 动力学预测器输出结构化状态 |
| A2 层级依赖 | [C1][C2] 保证 L3 只做连续表征, 物体离散化交由 L4 |
| A3 压缩保真 | 不确定性通道 [44:46], 显式跟踪信息损失 |
| A4 预测最小化 | µPC 训练框架, F = Σ ε·precision |
| A5 不确定性守恒 | 每消息带 precision 域, 逐层传播 |
| A6 组合完备 | 46维通道分解: geometry + semantics + affordance |
| A7 时间因果 | 位置编码含时间, 动力学预测不泄露未来 |
| A8 资源有限 | 快/慢切换 + 计算预算 2~25ms < 50ms cognitive cycle |
| A9 自指安全 | 不确定性输出 → L5 监控 → 可纠错性 |
| A10 伦理前置 | L3 渲染输出不含决策, 决策交由 L4/L5 |

## D1：因果推理的深度学习化

### 🎯 变分因果推断 (VCI)

「Counterfactual Generative Modeling with Variational Causal Inference」(2024-10, arXiv:2410.12730):

> 负面论证: CVAE 条件变分自编码器**根本上不适合因果推断中的反事实**
> 正面方案: 新型变分贝叶斯因果推断框架 →
>   - **无任何反事实样本**即可进行端到端反事实监督训练
>   - 解缠的外生噪声外溯 (disentangled exogenous noise abduction)
>   - 正确识别反事实生成中的因果效应

**三阶段推理** (Peal 的因果阶梯):
```
L1: 关联 P(Y|X) — 看到什么
L2: 干预 P(Y|do(X)) — 做什么会发生什么
L3: 反事实 P(Y_{x}|X',Y') — 假如...会怎样

白皮书的 L4 目标: 实现 L2+L3
```

### Neural Causal Models (NCM)

「Neural Causal Models for Counterfactual Identification and Estimation」(2022):

> 用神经网络表示**结构因果模型**中的结构方程
> 统一识别与估计——以前是两个分离步骤
> 在高维场景（图像、基因）中，NCM 可以直接从数据学习因果机制

### 因果生成模型综述

「From Identifiable Causal Representations to Controllable Counterfactual Generation」(2023):

> 完整路线图: 可识别因果表征 → 可控反事实生成
> 应用跨: 公平性、隐私、OOD 泛化、精准医疗、生物科学
> 核心挑战: 从观测数据中学习**可识别**的因果表征——仅靠统计正则化不足

**对白皮书的支撑**: 白皮书 L4 需要可识别因果表征——全局态 G(t) 应先做因果发现（从 L3 的神经场中出因果图），再做干预/反事实。综述为这条路线提供了完整理论基础。

## D2：因果发现与结构学习

### ILS-CSL: LLM 监督的因果结构学习

「Iterative LLM Supervised Causal Structure Learning」(2023, arXiv:2311.11689):

> LLM 因果推断 + 因果结构学习 (CSL) 的**迭代**融合
> LLM 提供的因果约束（来自预训练知识）→ 指导 DAG 学习
> DAG 的反馈 → 优化 LLM 的下一次推理
> 8 个真实数据集上超越 SOTA

**架构循环**:
```
LLM → (因果约束) → CSL → (精炼 DAG)
  ↑                    ↓
  └── (反馈/q) ←── 新 DAG 检查
```

### 因果知识蒸馏与实体交互检测

「Evaluating LLMs for Causal Modeling」(2024-11):

> 两项新任务: ① 因果领域知识蒸馏为因果变量; ② 交互实体检测
> GPT-4-turbo + Llama3-70b: **蒸馏因果变量**更强（比稀疏专家模型 Mixtral-8×22b）
> Mixtral: **识别交互实体**更强
> 关键依赖: 实体生成的领域 → LLM 的因果建模性能

「Causality Elicitation from LLMs」(2026-03):
> 5 步管道: LLM 采样文档 → 提取事件列表 → 跨文档规约为典范事件 → 二元指标向量 → 因果发现估计
> 不保证真实世界因果性，但提供**可检视的候选图集**
> 清晰界定：LLM 是假设生成器，不是因果真理机

### 对白皮书的启示

白皮书 L4 的因果图不应是人手工标注的——应该从 L3 神经场世界模型的"运行"中**自动发现**。ILS-CSL 的"迭代精炼"为这一发现过程提供了方法论框架。

## D3：LLM 与因果关系——能力与局限

### 🎯 基准研究：「Causal Reasoning and LLMs」(2023)

(arXiv:2305.00050)

> **系统性行为研究**——非理论分析，是实证
>
> | 任务 | LLM 性能 | 提升 |
> |------|----------|------|
> | 成对因果发现 | 97% | +13% vs 最佳方法 |
> | 反事实推理 | 92% | +20% vs 最佳方法 |
> | 事件因果性 | 86% | 必要+充分原因判断 |
>
> **泛化证明**: 特地为训练截止后构建的新数据集上仍然有效
> **不等于**: 人类级因果理解——失败模式不可预测
> **实际价值**: 作为人类专家的**辅助**，不是替代

### 「LLMs are Causal Parrots」

「Causality for Large Language Models」(2024-10, arXiv:2410.15319):

> LLMs 能**背诵**因果知识——不能真正理解或应用
> prompt 工程激活的是**已存储的语料中的因果关联**——不是"理解"因果
> 实质问题: **如何将因果嵌入训练过程**——在 token 嵌入学习→基础模型训练→微调→对齐→推理→评估的**每个环节**
> 六个未来方向中，核心是: **从"LLM 学会因果" → "设计因果原生的架构"**

### DEMOCRITUS: Large Causal Models from LLMs

「DEMOCRITUS」(2025-12, arXiv:2512.07796):

> 新范式: **大型因果模型 (LCM)** 从 LLM 构建
> LLM 用于: 提议主题 → 生成因果问题 → 从多域抽取因果陈述
> 技术挑战: 孤立+碎片化+歧义 → 编织为一致的**因果三元组 (RDF)** → 嵌入 LCM
> 新发明的**范畴机器学习方法**使之可能
> 跨域应用: 考古/生物/气候/经济/医学/技术

**对白皮书的批判**: DEMOCRITUS 从文本中抽取因果——白皮书 L4 是从**神经场世界模型的运行中**直接学习因果。文本因果是"二手"的；世界模型因果是"一手"的。两者互补——LLM 的因果知识可作为先验注入 L4，但不应是唯一来源。

## D4：因果抽象——粒度的桥梁

### 🎯 因果抽象的形式理论

「Abstracting Causal Models」(2018):
> 四层严格度递增的因果抽象定义:
> - **精确变换** (Rubenstein 2017): 最基本
> - **均匀变换**: 消除分布选择隐藏的差异
> - **抽象**: 干预集由低层→高层状态映射决定
> - **强抽象**: 考虑模型中的**所有潜在干预**，不只是允许的

关键洞察: **将微观变量合并为宏观变量的标准过程 = 强抽象的特例**

### 学习因果抽象

「Learning Causal Abstractions」(2024-06, arXiv:2406.00394):

> 线性因果模型的抽象学习
> 引入 **Abs-LiNGAM**:
>   - 先学高层模型（快速）
>   - 用高层模型约束 + 抽象函数 → 加速底层大模型恢复
> 有效性: 模拟数据上因果发现的可扩展性显著提升

**三个理论贡献**:
1. 低层系数 + 抽象函数 → 确定高层系数
2. 高层模型 → 约束低层变量的因果排序
3. 非高斯噪声 → LiNGAM 可识别

### 对白皮书的支撑

白皮书的"概念空间紧缩为因果表达"就是因果抽象的一个实例:

```
L3 概念空间 (连续) → 抽象函数 A → L4 因果图 (离散)

类比: 低层 SCM → 抽象 → 高层 SCM
白皮书: L3 → 因果紧缩 → L4
```

Abs-LiNGAM 的学习流程可直接映射到 L4 的实现: L3 的神经场是"低层模型"——高维连续；L4 学到的因果 DAG 是"高层模型"——低维离散。抽象函数将连续概念空间中的关系压缩为因果图的边。

## 综述的三条核心论据

### 论据 1: 反事实不是"生成变体"

VCI (2024) 清晰指出: CVAE 做的是"生成变体"，不是反事实。反事实涉及因果外溯——重建外生噪声、修改因果变量、传播改变。白皮书 L4 需要 VCI 式的变分因果推断，而非 naive 的条件生成。**反事实不是 imagine what if——反事实是 abduct-retract-predict。**

### 论据 2: LLM 是因果的加速器，不是引擎

ILS-CSL 和 DEMOCRITUS 证明 LLM 可以在因果发现中提供强大先验。但「Causal Parrots」论证的阴暗面同样成立——LLM 在"背诵"因果知识，不是"理解"因果。白皮书 L4 不应该像一个依赖外部 LLM API 的因果查询器——L4 应该是因果推理的**原生引擎**，LLM 知识仅作为未见的先验注入。

### 论据 3: 因果抽象是 L3↔L4 的正式桥梁

白皮书说"概念空间紧缩为因果表达"——听起来像哲学隐喻。「Abstracting Causal Models」提供了严谨的数学定义。Abs-LiNGAM 提供了可学习的算法。L3 的神经场世界模型 (连续) → L4 的因果 DAG (离散) 不是魔法——是因果抽象的一个实例。抽象函数 A: ℝ^∞ → {0,1}^{n×n} 就是"概念紧缩"的数学对应。

## 一、问题陈述

### 1.1 线性抽象的局限

现有因果抽象框架 (Rubenstein et al. 2018 / Abs-LiNGAM 2024) 仅处理**线性结构方程模型 (SCM)**。限制：

1. **线性 SCM**: F_i(X) = Σ β_ij · X_j + ε_i → 需要 X_j 独立加性贡献
2. **线性抽象映射**: Π: v → V 是线性满射 → 不能将非线性组合概念映射为一个符号
3. **线性干预等效**: do(X=x) 的因果效应保持在线性变换下

然而 L3→L4 的跨层抽象本质上是**非线性的**：

- L3 神经场是高度非线性的 (SIREN sin 组合)
- L4 符号概念 (如 "球碰撞 → 反弹") 对应 L3 中的非线性轨迹簇
- 抽象映射 A: S₃ → S₄ 将连续场 "折叠" 到离散概念 — 必然是高度非线性的

### 1.2 目标

将因果抽象形式化从**线性 SCM + 线性抽象映射**推广到**任意 (可测) SCM + (可微) 非线性抽象**。

## 二、形式框架

### 2.1 基础定义

**Def 2.1 (非线性 SCM)**. 结构因果模型 M = (V, U, F, P_U) 其中：

- V = {V₁, ..., V_n} 内生变量 (可取值在任意可测空间)
- U = {U₁, ..., U_m} 外生噪声
- F_i: (Pa(V_i), U_i) → V_i 是**任意可测函数** (不限制为线性)
- P_U 定义 U 上的联合分布

线性 SCM 是特例：F_i = Σ β_Pa · Pa + ε_i

**Def 2.2 (非线性抽象映射)**. 设 M_H = (V_H, U_H, F_H, P_{U_H}) 为高层模型，M_L = (V_L, U_L, F_L, P_{U_L}) 为低层模型。非线性抽象映射 τ: dom(V_L) → dom(V_H) 满足：

1. τ 是**满射** (每个高层值至少对应一个低层值)
2. τ 是**可微** (或分区可微，允许离散化)
3. **干预交换** (核心公理): 对所有 I ⊂ L 及其 complement J = L\I:

```
τ_*(P(V_J | do(V_I = v_I))) = P(τ(V_J) | do(τ(V_I) = τ(v_I)))
```

其中 τ_* 是 τ 诱导的分布的 pushforward。

**Def 2.3 (非线性因果抽象)**. 称 M_L 的 (非线性) 因果抽象为 M_H，记 M_H = α(M_L, τ)，若存在非线性抽象映射 τ: dom(V_L) → dom(V_H) 使得干预交换条件对 M_L 中所有合法干预和 M_H 中对应的干预成立。

### 2.2 与线性框架的比较

| 性质 | 线性框架 (Rubenstein) | 非线性框架 (本理论) |
|------|----------------------|---------------------|
| F 形式 | F_i = Σ β_ij X_j + ε_i | F_i: (Pa, U_i) → V_i 任意可测 |
| τ 形式 | τ(v) = Π v (线性满射矩阵) | τ: dom(V_L) → dom(V_H) 可微满射 |
| 干预交换 | 𝔼[Y|do(X)] = β_Y X | dist(Y|do(X)) = τ_* dist(V_J|do(V_I)) |
| 抽象保真度 | MSE(β_H − Π β_L Π^T) | Wasserstein(τ_* P_L, P_H) |
| 压缩率 | dim(H) / dim(L) | |V_H| / |V_L| 概念数比 |

### 2.3 核心定理

**Thm 2.1 (非线性抽象存在性)**. 对任意低层非线性 SCM M_L，存在高层非线性 SCM M_H 及非线性抽象映射 τ 使得 M_H = α(M_L, τ) 若：

1. M_L 满足因果充分性 (无未观测混杂)
2. τ 的纤维 {v_L: τ(v_L) = v_H} 在因果意义下是均匀的 (同质分区)

**证明思路** (构造性):

定义等价关系 ∼_τ: v_L ∼_τ v'_L ⇔ τ(v_L) = τ(v'_L)

定义 V_H 上的条件分布: 
P(V_H = v_H | Pa_H) = τ_*(P(V_L ∈ τ⁻¹(v_H) | Pa_L ⊂ τ⁻¹(Pa_H)))

若纤维均匀，该定义在纤维内保持一致性，M_H 的因果语义由 M_L 通过 τ 继承。

**Thm 2.2 (非线性抽象保真度界)**. 设 M_H = α(M_L, τ)，则对任意观察/干预查询 Q:

```
|Q(M_L) − Q(M_H)| ≤ L_τ · d(τ, τ_opt)
```

其中 L_τ 是 τ 的 Lipschitz 常数，d 是抽象映射间的度量。

**关键推论**: 更平滑的映射 (低 Lipschitz) 比突变映射更保真。

## 三、非线性抽象结构

### 3.1 抽象层级

```
Level 4 (符号):       A → B → C      离散因果图
                         ↑ τ₃ (离散化 softmax)
Level 3.5 (概念):     "球A" "碰撞" "B"  连续概念嵌入
                         ↑ τ₂ (注意力池化 + 投影)
Level 3 (场):         φ_A(x) φ_B(x) ...  对象槽场
                         ↑ τ₁ (槽注意力分解)
Level 3 (共享场):     Φ(x): ℝ³ → ℝ⁴⁶   全局神经场
```

### 3.2 学习算法框架

```python
# NonlinearAbs: 非线性因果抽象学习器

class NonlinearCausalAbstraction(nn.Module):
    """
    学习非线性因果抽象映射 τ: S₃ → S₄

    三层抽象:
        τ₁: 场 → 对象槽  (SlotAttention)
        τ₂: 对象槽 → 概念嵌入 (Transformer + 池化)
        τ₃: 概念嵌入 → 符号 (软离散化 / Gumbel-Softmax)
    """

    def __init__(
        self,
        field_dim: int = 46,
        num_slots: int = 5,
        slot_dim: int = 128,
        concept_dim: int = 64,
        num_concepts: int = 10,   # 离散概念数上限
    ):
        super().__init__()

        # τ₁: 场 → 槽
        self.slot_attention = SlotAttention(
            num_slots=num_slots,
            slot_dim=slot_dim,
            feature_dim=field_dim,
        )

        # τ₂: 槽 → 概念嵌入
        self.concept_encoder = nn.Sequential(
            nn.Linear(slot_dim, concept_dim * 2),
            nn.LayerNorm(concept_dim * 2),
            nn.GELU(),
            nn.Linear(concept_dim * 2, concept_dim),
        )

        # τ₃: 概念嵌入 → 符号 (软离散化)
        self.concept_prototypes = nn.Parameter(
            torch.randn(num_concepts, concept_dim) * 0.02
        )
        self.temperature = 1.0

    def forward(self, fields: torch.Tensor):
        """
        Args:
            fields: (B, N, 46) 神经场在采样点的值
        Returns:
            symbols: (B, K, N_concepts) 软符号分配
            concepts: (B, K, concept_dim) 概念嵌入
            attention: (B, K, N) 槽注意力
        """
        # τ₁
        slots, attn = self.slot_attention(fields)

        # τ₂
        concepts = self.concept_encoder(slots)  # (B, K, D)
        concepts = F.normalize(concepts, dim=-1)

        # τ₃: Gumbel-Softmax 到符号
        logits = torch.matmul(
            concepts, self.concept_prototypes.T
        ) / self.temperature  # (B, K, N_concepts)

        if self.training:
            symbols = F.gumbel_softmax(logits, tau=self.temperature, hard=False)
        else:
            symbols = F.softmax(logits, dim=-1)

        return symbols, concepts, attn

    def compute_abstraction_loss(
        self,
        fields_t: torch.Tensor,
        fields_t1: torch.Tensor,
        actions: Optional[torch.Tensor] = None,
    ) -> dict:
        """
        抽象保真度损失: 确保符号层的因果动力学可预测

        L_abs = L_pred + λ_compress · L_entropy + λ_causal · L_intervention

        关键: 该损失驱动 τ 自动寻找「因果上最有信息量」的抽象
        """
        symbols_t, concepts_t, _ = self(fields_t)
        symbols_t1, concepts_t1, _ = self(fields_t1)

        # 1. 预测损失: 符号动力学可预测性
        #    symbol_t → symbol_t1 的转移必须低熵
        #    使用因果Transformer解码
        pred = self.causal_transformer(symbols_t, actions)
        L_pred = F.cross_entropy(pred, symbols_t1.argmax(dim=-1))

        # 2. 压缩损失: 概念熵 (鼓励紧凑离散化)
        probs = symbols_t.mean(dim=(0, 1))  # (N_concepts,)
        L_entropy = -(probs * torch.log(probs + 1e-8)).sum()

        # 3. 因果损失: 干预区分性
        #    不同动作应导致明显不同的符号转移
        if actions is not None:
            L_causal = self.intervention_separation_loss(
                symbols_t, symbols_t1, actions
            )
        else:
            L_causal = 0.0

        return {
            "L_pred": L_pred,
            "L_entropy": L_entropy,
            "L_causal": L_causal,
            "total": L_pred - 0.01 * L_entropy + 0.1 * L_causal,
        }
```

### 3.3 关键技术细节

#### 3.3.1 纤维均匀性约束

非线性抽象的核心就是 τ 的纤维 {v_L: τ(v_L) = v_H} 在因果意义下同质。我们通过**对比学习**来近似：

```python
def fiber_contrastive_loss(
    tau, fields, labels
):
    """
    鼓励同一抽象标签的场在因果隐空间中接近

    直觉: 两块 "球在飞" 的场 → τ 都应该映射到 "飞" 概念
          即使它们的低层场分布不同
    """
    z = tau(fields)  # concepts
    return supervised_contrastive_loss(z, labels)
```

#### 3.3.2 干预分离度

因果抽象最关键的性质：不同干预 → 不同的符号转移。

```python
def intervention_separation(symbols_before, symbols_after, intervention):
    """
    测度: 同一干预内部转移一致性高, 不同干预间转移差异大
    """
    # 按干预分组
    unique_intv = intervention.unique()
    
    intra_dists = []
    inter_dists = []
    
    for a in unique_intv:
        mask_a = (intervention == a)
        # 组内距离
        transfer_a = torch.cat([
            symbols_before[mask_a], symbols_after[mask_a]
        ], dim=-1)
        intra_dists.append(torch.pdist(transfer_a).mean())
        
        for b in unique_intv:
            if a >= b: continue
            mask_b = (intervention == b)
            transfer_b = torch.cat([
                symbols_before[mask_b], symbols_after[mask_b]
            ], dim=-1)
            inter_dists.append(
                torch.cdist(transfer_a.mean(0, keepdim=True),
                           transfer_b.mean(0, keepdim=True)).mean()
            )
    
    # 期望: intra 小, inter 大
    return torch.stack(intra_dists).mean() - torch.stack(inter_dists).mean()
```

## 四、非线性因果抽象的三个层次

### 4.1 Level 1: 参数抽象 (通过可微 τ)

```
M_L (非线性)  →  τ (可微)  →  M_H (任意)

关键: τ 可微 → 可端到端梯度优化
代价: τ 必须连续 → 不能直接输出硬类别
解法: Gumbel-Softmax 桥接
```

### 4.2 Level 2: 结构抽象 (通过因果边缘化)

```
M_L 的因果图 G_L  →  τ 诱导的分区  →  G_H

G_H 中边 A_H → B_H 存在 ⇔
  ∃ a ∈ τ⁻¹(A_H), b ∈ τ⁻¹(B_H) 使得 G_L 中存在 a → b 路径
  且该路径不经过其他 marginalization 分区

实际上: G_H = quotient graph of G_L by ∼_τ
```

### 4.3 Level 3: 语义抽象 (通过因果干预等价)

```
两个低层状态 v_L, v'_L 属于同一高层概念 v_H ⇔

  对任意干预 do(X=x) 和任意目标变量 Y,
  P(Y|do(X=x), V_L=v_L) ≈ P(Y|do(X=x), V_L=v'_L)

即: 两个低层状态在因果意义上"不可区分"
```

这是因果抽象的黄金标准 — 完全基于行为的等价性，而非表象相似。

| 指标 | 公式 | 目标 |
|------|------|------|
| 干预保真度 | 1 − JS(P_H(Y\|do(X)) ‖ P_L(Y\|do(X))) | > 0.95 |
| 压缩比 | \|V_H\| / \|V_L\| | < 0.3 |
| 结构一致性 | SHD(G_H, G_true) | < 2 |
| 抽象稳定性 | Var(learned τ across seeds) | 低 |

### 5.3 消融实验

| 消融项 | 预测 |
|--------|------|
| 移除 Gumbel-Softmax → hard argmax | 丧失梯度 — 无法端到端优化 τ |
| 移除对比纤维损失 | 概念坍缩 — 所有状态映射到同一符号 |
| 移除因果项 (只保留 recon loss) | 学到的概念是表象相关，非因果相关 |
| 线性 τ vs 非线性 τ | 非线性 τ 在非线性底层上保真度显著更高 |
| τ 维度 | 概念维度 D∈{16,32,64,128}: 64 应该是最优点 |

## 六、与 L3↔L4 桥接的具体对接

### 6.1 从因果紧缩算法到非线性抽象

因果紧缩算法 v1.0 的五阶段流水线完全在非线性抽象框架下工作：

```
Stage 1 (概念分割)    → 纤维近似 (对比学习)
Stage 2 (因果发现)    → G_H 结构推断 (quotient graph)
Stage 3 (结构方程学习)  → F_H 拟合 (条件生成模型)
Stage 4 (抽象验证)    → 干预交换检验
Stage 5 (迭代精炼)    → τ 梯度优化
```

### 6.2 数学改进

原算法中 Stage 4 的抽象验证使用 Abs-LiNGAM 作为基线，但 Abs-LiNGAM 只能处理线性 SCM。新的非线性理论允许：

1. 用**Wasserstein距离**替代 KL 散度来比较分布 (更适合连续→离散映射)
2. 用**距离协方差 (dCor)** 来检测非线性依赖，替代偏相关系数
3. 用**条件独立性约束优化 (CICO)** 来确保抽象不引入伪因果

## 八、代码框架: 最小可用实现

```python
# nonlinear_causal_abstraction/minimal_demo.py

"""
最小演示: 通过非线性因果抽象发现摆锤的3个宏观概念
"""

import torch
import torch.nn as nn
import numpy as np


def pendulum_sim(theta0, omega0, dt=0.05, steps=1000):
    """非线性摆: θ̈ = -g/L sin(θ) - b·θ̇"""
    g, L, b = 9.81, 1.0, 0.1
    theta, omega = theta0, omega0
    trajectory = []
    for _ in range(steps):
        trajectory.append([theta, omega])
        alpha = -(g / L) * np.sin(theta) - b * omega
        omega += alpha * dt
        theta += omega * dt
    return np.array(trajectory)


# 生成数据
data = []
for _ in range(100):
    traj = pendulum_sim(np.random.uniform(-np.pi, np.pi), np.random.uniform(-2, 2))
    data.append(traj)
data = np.stack(data)  # (100, 1000, 2)

# 转换为神经场风格 (每个时间点 → "虚拟场值")
# 将(theta, omega)映射到"虚拟采样点"上
field_data = torch.tensor(data, dtype=torch.float32)  # (100, 1000, 2)


class MinimalTau(nn.Module):
    """最小 τ: 2D → 3 概念 (softmax)"""
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 64),
            nn.GELU(),
            nn.Linear(64, 32),
            nn.GELU(),
            nn.Linear(32, 3),  # 3 concepts: left, center, right
        )

    def forward(self, x):
        return F.softmax(self.net(x), dim=-1)


# 训练: 自监督预测 + 因果分离
tau = MinimalTau()
optimizer = torch.optim.Adam(tau.parameters(), lr=1e-3)

for epoch in range(100):
    # 取一段序列
    batch = field_data[:16]  # (16, 1000, 2)

    # 前向 → 抽象
    symbols = tau(batch)  # (16, 1000, 3)

    # 预测损失: t→t+1
    pred_loss = F.mse_loss(symbols[:, 1:], symbols[:, :-1].detach())

    # 熵正则 (紧凑)
    avg_probs = symbols.mean(dim=(0, 1))
    ent_loss = -(avg_probs * torch.log(avg_probs + 1e-8)).sum()

    loss = pred_loss - 0.01 * ent_loss
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

# 结果: 检查符号分配是否与物理语义 (左/中/右) 一致
print("Converged. Checking concept assignments...")
```

## 零、动机

### 0.1 核心问题

AGI 必须整合异构感官通道（视觉、听觉、触觉、本体感觉、语言），但每个通道的表征空间完全不同：

| 模态 | 表征空间 | 维度 | 拓扑 |
|------|---------|------|------|
| 视觉 | 像素 / 神经场 | ℝ^(H×W×3) / C⁰(ℝ³,ℝ⁴⁶) | 网格 / 连续 |
| 听觉 | 频谱图 / 波形 | ℂ^(F×T) | 卷积几何 |
| 触觉 | 力 / 力矩 / 纹理 | ℝ⁶ × ℝ^(N_taxels) | 体感嵌入 |
| 本体感觉 | 关节角 / 速度 | ℝ^(N_dofs) | 流形 (toroidal) |
| 语言 | token 嵌入 | ℝ^(N_tokens × D) | 预训练度量 |

**根本问题**: 这些异构空间中的「同一个概念」（如 "球"）如何在 L3 世界模型中统一为**同一个对象槽**？

### 0.2 为什么不是简单的跨模态预训练

CLIP-style 对比学习 (vision↔language) 的局限：

- 只对齐两个模态对的**静态嵌入**，不保持因果结构
- 不区分 "球" 的 visual appearance 和 causal role 的对齐
- 自下而上的关联 → 无法处理全新的、未见过的多模态组合

**我们需要的是**: **因果意义上的对齐** — 不同模态输入必须导致相同的因果预测结果，而非仅仅相似的表征。

## 一、形式框架

### 1.1 多模态概念 = 因果关系不变类

**Def 1.1 (因果概念)**. 概念 C 定义为一个**因果关系不变类**：

```
C = { (modality_m, x_m) : ∀ 干预 do(I), dist(effect | input=x_m) 在所有 m 间一致 }
```

即：来自不同模态但表征**同一概念**的输入，在任何干预下的因果效应分布必须相同。

**对比**:
- 表象对齐: "球" 的视觉嵌入 ≈ "球" 的听觉嵌入
- 因果对齐: do(推球) 在视觉观测 → 速度变化 = do(推球) 在触觉观测 → 速度变化

### 1.2 概念空间 C

**Def 1.2 (概念空间)**. 概念空间 C 是一个测度空间 (C, d_C, μ_C)，其中：

- C 的元素是因果概念
- d_C: C × C → ℝ⁺ 是概念间距离 (因果语义距离)
- μ_C 是概念先验

**关键性质**: C 独立于任何特定模态 — 它是因果完备的抽象空间。

### 1.3 模态编码器

**Def 1.3 (模态编码器)**. 对于模态 m ∈ M = {vis, aud, tac, prop, lang}:

编码器 E_m: X_m → Δ(C)
将模态特定输入映射到**概念空间上的分布**。

注意: 输出是分布而非点估计 — 反映感知不确定性 (符合公理 A7: 不确定性守恒)。

### 1.4 多模态融合算子

**Def 1.4 (融合)**. 融合算子 ⊕: Δ(C) × Δ(C) → Δ(C) 合并多个模态的概念信念：

```
p(c | x₁, x₂, ..., x_K) = ⊕_{k=1}^K E_k(x_k)
```

融合必须满足：

1. **交换律**: ⊕(p₁, p₂) = ⊕(p₂, p₁)
2. **结合律**: ⊕(p₁, ⊕(p₂, p₃)) = ⊕(⊕(p₁, p₂), p₃)
3. **一致性**: 若 p₁ = p₂，则 ⊕(p₁, p₂) = p₁
4. **精度加权**: ⊕(p₁, p₂) ∝ p₁^(τ₁) · p₂^(τ₂) 其中 τ_k 为模态精度

## 二、学习框架

### 2.1 因果对比学习 (Causal Contrastive Learning)

标准对比学习 (InfoNCE):

```
L_NCE = -log [ exp(sim(z_i, z_j)/τ) / Σ_k exp(sim(z_i, z_k)/τ) ]
```

其中 z_i, z_j 是正样本对 (同一对象，不同模态)。

我们推广到**因果对比**:

```python
# CausalContrast: 对比的不只是客体身份，而是因果转移

def causal_contrastive_loss(
    z_query: torch.Tensor,       # 概念嵌入 (模态 A 的)
    z_key: torch.Tensor,         # 概念嵌入 (模态 B 的)
    z_effect_query: torch.Tensor, # do(intervention) 后的概念 (模态 A)
    z_effect_key: torch.Tensor,   # do(intervention) 后的概念 (模态 B)
    temperature: float = 0.07,
):
    """
    因果对比: 对齐不仅要求 "同一个 object"
    还要求 "同一干预产生相同效应"
    """
    batch_size = z_query.shape[0]

    # 身份对齐
    sim_identity = torch.matmul(
        F.normalize(z_query, dim=-1),
        F.normalize(z_key, dim=-1).T,
    ) / temperature

    # 因果效应对齐
    z_effect_diff_q = z_effect_query - z_query
    z_effect_diff_k = z_effect_key - z_key
    sim_causal = torch.matmul(
        F.normalize(z_effect_diff_q, dim=-1),
        F.normalize(z_effect_diff_k, dim=-1).T,
    ) / temperature

    # 联合对比
    sim = sim_identity + sim_causal
    labels = torch.arange(batch_size, device=z_query.device)

    loss_id = F.cross_entropy(sim_identity, labels)
    loss_causal = F.cross_entropy(sim_causal, labels)

    return loss_id + loss_causal
```

### 2.2 模态特定编码器

```python
class VisionEncoder(nn.Module):
    """视觉 → 概念空间: 神经场 → 槽 → 概念嵌入"""

    def __init__(self, concept_dim: int = 128, num_concepts: int = 16):
        super().__init__()
        # 神经场 backbone (共享)
        self.field_encoder = SIREN(
            hidden_features=256, hidden_layers=4, out_features=256
        )
        # 槽注意力
        self.slot_attn = SlotAttention(
            num_slots=8, slot_dim=128, feature_dim=256
        )
        # 槽 → 概念投影
        self.slot_to_concept = nn.Sequential(
            nn.Linear(128, concept_dim * 2),
            nn.LayerNorm(concept_dim * 2),
            nn.GELU(),
            nn.Linear(concept_dim * 2, concept_dim),
        )
        # 不确定性: 输出 μ 和 log σ
        self.mu_head = nn.Linear(concept_dim, concept_dim)
        self.log_sigma_head = nn.Linear(concept_dim, concept_dim)

    def forward(self, coords, rays=None):
        # 场特征
        field_feats = self.field_encoder(coords)  # (B, N, 256)
        # 槽
        slots, attn = self.slot_attn(field_feats)  # (B, K, 128)
        # 概念
        conc = self.slot_to_concept(slots)  # (B, K, D)
        mu = self.mu_head(conc)
        log_sigma = self.log_sigma_head(conc)
        return mu, log_sigma, attn  # 返回分布参数


class AudioEncoder(nn.Module):
    """听觉 → 概念空间: 音频频谱 → CNN → 槽注意力"""

    def __init__(self, concept_dim: int = 128):
        super().__init__()
        # 频谱处理
        self.spectrogram = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=7, stride=2, padding=3),
            nn.BatchNorm2d(32), nn.GELU(),
            nn.Conv2d(32, 64, kernel_size=5, stride=2, padding=2),
            nn.BatchNorm2d(64), nn.GELU(),
            nn.Conv2d(64, 128, kernel_size=3, stride=2, padding=1),
            nn.BatchNorm2d(128), nn.GELU(),
        )
        # 时间池化 → 固定长度序列
        self.temporal_pool = nn.AdaptiveAvgPool2d((None, 1))

        # 槽注意力
        self.slot_attn = SlotAttention(
            num_slots=8, slot_dim=128, feature_dim=128
        )
        self.slot_to_concept = nn.Linear(128, concept_dim * 2)

    def forward(self, waveform):
        # STFT → 频谱
        spec = torch.stft(
            waveform, n_fft=512, hop_length=128, return_complex=True
        ).abs().unsqueeze(1)  # (B, 1, F, T)

        feats = self.spectrogram(spec)  # (B, 128, F', T')
        feats = feats.permute(0, 3, 1, 2)  # (B, T', 128, F')
        feats = feats.reshape(feats.shape[0], feats.shape[1], -1)  # (B, T', ...)

        slots, attn = self.slot_attn(feats)

        params = self.slot_to_concept(slots)
        mu, log_sigma = params.chunk(2, dim=-1)
        return mu, log_sigma, attn


class ProprioceptiveEncoder(nn.Module):
    """本体感觉 → 概念空间: 关节向量 → MLP → 槽注意力"""

    def __init__(self, dof: int = 7, concept_dim: int = 128):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(dof, 128), nn.GELU(),
            nn.Linear(128, 256), nn.GELU(),
            nn.Linear(256, 128),
        )
        self.slot_attn = SlotAttention(
            num_slots=4, slot_dim=64, feature_dim=128
        )
        self.slot_to_concept = nn.Linear(64, concept_dim * 2)

    def forward(self, joint_angles, joint_velocities):
        x = torch.cat([joint_angles, joint_velocities], dim=-1)
        x = x.unsqueeze(1)  # (B, 1, 2*dof)
        feats = self.mlp(x)  # (B, 1, 128)
        slots, attn = self.slot_attn(feats)
        params = self.slot_to_concept(slots)
        mu, log_sigma = params.chunk(2, dim=-1)
        return mu, log_sigma, attn


class LanguageEncoder(nn.Module):
    """语言 → 概念空间: token 序列 → Transformer → 槽 → 概念"""

    def __init__(self, vocab_size: int = 32000, d_model: int = 512, concept_dim: int = 128):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)
        self.transformer = nn.TransformerEncoder(
            nn.TransformerEncoderLayer(
                d_model=d_model, nhead=8, dim_feedforward=2048,
                dropout=0.1, batch_first=True,
            ),
            num_layers=6,
        )
        self.slot_attn = SlotAttention(
            num_slots=8, slot_dim=128, feature_dim=d_model
        )
        self.slot_to_concept = nn.Linear(128, concept_dim * 2)

    def forward(self, tokens, attention_mask=None):
        x = self.embedding(tokens)  # (B, L, D)
        x = self.transformer(x, src_key_padding_mask=attention_mask)
        slots, attn = self.slot_attn(x)
        params = self.slot_to_concept(slots)
        mu, log_sigma = params.chunk(2, dim=-1)
        return mu, log_sigma, attn
```

### 2.3 精度加权融合

```python
class MultimodalFusion(nn.Module):
    """
    融合多模态概念信念 → 统一的 L3 对象槽

    公式: p(c | all_modalities) = ⊕_m E_m(x_m)
           ∝ Π_m p_m(c)^{τ_m}

    其中 τ_m = 1/σ²_m (精度 = 逆方差)
    """

    def __init__(self, num_modalities: int = 4, concept_dim: int = 128):
        super().__init__()
        self.concept_dim = concept_dim
        # 可学习的模态先验精度 (或由不确定性预测)
        self.default_precision = nn.Parameter(torch.ones(num_modalities))

    def forward(self, modal_mus, modal_log_sigmas, modal_mask=None):
        """
        Args:
            modal_mus: List[Tensor(B, K, D)] 各模态的均值
            modal_log_sigmas: List[Tensor(B, K, D)] 各模态的对数标准差
            modal_mask: Optional 指示哪些模态可用

        Returns:
            fused_mu: (B, K, D)
            fused_log_sigma: (B, K, D)
        """
        precisions = []
        weighted_mus = []

        for i, (mu, log_sigma) in enumerate(zip(modal_mus, modal_log_sigmas)):
            sigma2 = torch.exp(2 * log_sigma) + 1e-6
            tau = 1.0 / sigma2

            if modal_mask is not None:
                tau = tau * modal_mask[:, i, None, None].float()

            precisions.append(tau)
            weighted_mus.append(mu * tau)

        total_precision = torch.stack(precisions).sum(dim=0)  # (B, K, D)
        total_weighted = torch.stack(weighted_mus).sum(dim=0)  # (B, K, D)

        fused_mu = total_weighted / (total_precision + 1e-8)
        fused_log_sigma = -0.5 * torch.log(total_precision + 1e-8)

        return fused_mu, fused_log_sigma


# ============================================================
#  训练流程
# ============================================================

def train_multimodal_alignment(
    vision_enc, audio_enc, prop_enc, lang_enc,
    fusion, dataloader, epochs=100,
):
    """
    完整多模态对齐训练

    Phase 1: 模态内因果预训练 (各模态自监督)
    Phase 2: 模态间因果对比 (跨模态一致)
    Phase 3: 融合调优 (end-to-end)
    """
    optim = torch.optim.AdamW(
        list(vision_enc.parameters()) +
        list(audio_enc.parameters()) +
        list(prop_enc.parameters()) +
        list(lang_enc.parameters()) +
        list(fusion.parameters()),
        lr=1e-4, weight_decay=0.01,
    )

    for epoch in range(epochs):
        for batch in dataloader:
            vis, aud, prop, lang, interventions = batch

            # 编码各模态
            vis_mu, vis_sigma, _ = vision_enc(vis)
            aud_mu, aud_sigma, _ = audio_enc(aud)
            prop_mu, prop_sigma, _ = prop_enc(*prop)
            lang_mu, lang_sigma, _ = lang_enc(lang)

            # 因果对比损失 (相位 2)
            loss_causal = causal_contrastive_loss(
                vis_mu, aud_mu,
                vision_enc(apply_intervention(vis, interventions))[0],
                audio_enc(apply_intervention(aud, interventions))[0],
            )

            # 融合
            mus = [vis_mu, aud_mu, prop_mu, lang_mu]
            sigmas = [vis_sigma, aud_sigma, prop_sigma, lang_sigma]
            fused_mu, fused_sigma = fusion(mus, sigmas)

            # 重建损失 (相位 1): 从融合概念反推各模态
            recon_loss = 0
            for enc, (mu, sigma), data in [
                (vision_enc, (vis_mu, vis_sigma), vis),
                (audio_enc, (aud_mu, aud_sigma), aud),
            ]:
                recon = enc.decoder(mu + sigma * torch.randn_like(sigma))
                recon_loss += F.mse_loss(recon, data)

            # 总损失
            loss = recon_loss * 0.1 + loss_causal
            optim.zero_grad()
            loss.backward()
            optim.step()

        print(f"Epoch {epoch}: loss={loss.item():.4f}")
```

## 三、概念空间几何

### 3.1 距离公理

概念空间 C 必须配备有意义的距离度量 d_C:

```
d_C(c₁, c₂) = α · d_causal(c₁, c₂) + (1−α) · d_semantic(c₁, c₂)
```

其中:

- **d_causal**: 因果距离 = E_{do(X)} [Wasserstein(P(effect|c₁, do(X)), P(effect|c₂, do(X)))]
- **d_semantic**: 语义距离 = 1 − cos(embed(c₁), embed(c₂)) (标准嵌入距离)

α ∈ [0,1] 控制因果权重; 随训练从 0→~0.7 退火 (先用语义对齐，后强调因果一致性)。

### 3.2 Gärdenfors 概念空间映射

概念空间 C 直接对接 Gärdenfors 的概念几何框架:

```
概念 = 凸区域 in C (自然属性)
概念原型 = 区域的 Voronoi 中心
```

这使 C 成为白皮书 v0.2 中「概念空间几何」模块的具体实现。

### 3.3 概念组合

受公理 A5 (组合完备公理) 要求，概念空间必须支持组合:

```
compose(c₁, c₂) → c_new ∈ C

要求: c_new 的因果属性 = compose_causal(c₁的因果属性, c₂的因果属性)
```

一个可行方案: **张量积表示** (TensoRT, Smolensky 1990):

```
embed(c₁ ∘ c₂) = embed(c₁) ⊗ embed(c₂)  → 展平 → 投影到 C
```

该方案保证了组合的系统性和递归性。

## 四、评估协议

### 4.1 多模态对齐度

| 指标 | 描述 | 目标 |
|------|------|------|
| Causal Invariance Score | 同一概念在不同模态下的因果效应差异 | < 0.1 (KL) |
| Cross-modal Retrieval | 文本 "红球" → 视觉场中红球槽的 top-1 准确率 | > 90% |
| Concept Purity | 同一槽在不同模态下的概念一致性 (归一化互信息) | NMI > 0.8 |
| Uncertainty Calibration | 预测的不确定性与实际误差是否一致 | ECE < 0.05 |
| Zero-shot Composition | 未见过的概念组合 (如 "弹跳的金属球") | top-5 > 70% |

### 4.2 基准数据集

```
MultimodalCausalBench:
├── CausalPong-MM         (视觉 + 听觉 + 触觉碰撞)
├── Kitchen-MM            (RGB-D + 力传感器 + 语音指令)
├── Physics-MM            (MuJoCo + 碰撞音 + 关节力)
└── Abstract-MM           (合成概念: 图形/声音/语言对应)
```

### 4.3 消融矩阵

| 消融 | 预测效果 |
|------|---------|
| 无因果对比 (只用 InfoNCE) | 跨模态检索尚可，但因果不变性差 |
| 无精度加权 (等权重融合) | 噪声模态拉低整体性能 |
| 无槽分解 (单个全局嵌入) | 无法处理多对象场景 |
| 无概念空间正则 | 概念坍缩，缺乏几何结构 |

## 六、关键发现与设计原则

1. **因果对齐 > 表象对齐**: 跨模态一致的本质是因果不可区分性，不是嵌入相似度
2. **不确定性是精度权重的来源**: 低置信度模态应该被融合自动降权
3. **概念空间是因果的**: 距离度量必须反映因果结构，不是纯语义
4. **组合性是测试 AGI 的试金石**: 能否从 "球"+"弹跳" 自然地组合为 "弹跳球"？
5. **槽是跨模态通用接口**: 对象槽同时作为 (a) 模态内分解 (b) 模态间对齐点

---

**核心贡献**: 将多模态整合从「嵌入对齐」提升到「因果对齐」，使 L3 世界模型的输入统一于因果不变概念，而非表象特征。

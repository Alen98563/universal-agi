## 第零部分: 实验设计方法论

### 实验层级

- **层级 0 (单元)**: 单层、单公理、纯模拟数据
- **层级 1 (组件)**: 2层联合、合成场景
- **层级 2 (集成)**: 3+层、MuJoCo 环境
- **层级 3 (对抗)**: 刻意违反公理的破坏性测试

### 通用度量

| 度量 | 符号 | 含义 | 适用范围 |
|------|------|------|----------|
| PSNR | P_snr | 重建质量 (dB) | L3 神经场 |
| 预测误差 | ||eps||_2 | L2/L3 预测残差 | L2-L4 |
| 结构汉明距离 | SHD | 因果图恢复精度 | L4 |
| 反事实精度 | CFA | 反事实预测准确率 | L4 |
| meta-d' | d'_meta | 元认知敏感度 | L5 |
| 认知周期 | T_cycle | ms/周期 (≤50ms) | 全局 |
| ARI / mIoU | — | 分割/槽质量 | L3 |
| 校准误差 | ECE | 置信度-准确率偏差 | L5 |

### 成功标准分级

| 等级 | 含义 | 示例 |
|------|------|------|
| **S** (Showstopper) | 失败则框架基本假设错误 | 预测误差不收敛于物理规律场景 |
| **C** (Critical) | 失败则对应公理待修正 | 因果抽象不能保持干预等效 |
| **I** (Informative) | 失败提供边界信息 | µP 在 512 层时退化 |

## 第一部分: L1-L2 单元实验

### E1.1: 感知编码 — Rate-Distortion 权衡 (公理 A3)

**目标**: 验证 L1→L2 压缩符合 rate-distortion 信息论下界。

- **输入**: MuJoCo RGB 序列 (64×64, 30fps)
- **方法**: VAE, latent dim ∈ {8, 16, 32, 64, 128} (调节 rate)
- **度量**: MSE (distortion) vs KL(q||p) (rate) → R-D 曲线
- **成功标准 (C)**: R-D 曲线位于 Shannon 下界 20% 以内; 潜在 z 可线性解码物体位置
- **预算**: 1 GPU·天

### E1.2: 紧急反射 — L1→L2 短路延迟 (公理 A8, A10)

**目标**: 验证紧急反射在 <20ms 完成 L1→L2 短路。

- **场景**: MuJoCo 自由落体 (球从上方掉落)
- **触发**: 加速度计 >15m/s² → L1→L2 直连
- **成功标准 (S)**: 延迟 <20ms; 0 假阳性; 100% 真阳性触发
- **预算**: 0.5 GPU·天

### E1.3: 跨模态时序对齐 (公理 A6)

验证视觉-触觉-本体感觉的时序对齐。随机偏置某一模态 ±50ms → 检测精度 >10ms。

- **成功标准 (C)**: 检测到 >10ms 偏移; 对齐后融合 PSNR > 非对齐
- **预算**: 1 GPU·天

**继承**: M0 SIREN 实现文档 (tmp_m0_siren.md)

| 实验 ID | 场景 | ω₀ | 层×宽 | 目标 PSNR |
|--------|------|-----|-------|----------|

**止损**: 若 E2.1a PSNR < 25dB (Day 3) → 换 InstantNGP 哈希网格。**预算**: 2 GPU·天。

### E2.2: 因果 Pong 基准 (公理 A7)

**场景**: 3 球 (A 受控、B 目标、C 障碍)。A 必须在推测 C 的未来轨迹后规划碰撞 B。

| 度量 | 目标 |
|------|------|
| 因果发现率 (A→B vs A→C) | >95% |
| 反事实准确率 | >90% |
| vs DreamerV3 (1/4 数据) | MVE > DV3 |
| 推理速度 | <5ms |

**成功标准 (S)**: 因果发现率 >95%。若 <80%，公理 A7 的「因果可从遮掩涌现」假说被证伪。**预算**: 3 GPU·天。

| 深度 | 物体数 | 目标 PSNR | 目标收敛 |
|------|--------|----------|---------|
| 8 | 3 | >28dB | 10k |
| 16 | 5 | >26dB | 20k |
| 32 | 5 | >24dB | 40k |
| 64 | 7 | >22dB | 80k |
| 128 | 7 | >20dB | 160k |

**预算**: 5 GPU·天 (大头)。

## 第三部分: L4 因果推理实验

### E3.1: do-Calculus 三阶段验证 (公理 A1)

因果图 X→M→Y, X←C→Y。辨识→估计→反事实全流程验证。

- **成功标准 (C)**: do-effect 误差 <10%; 正确拒绝不可辨识查询
- **预算**: 1 GPU·天

### E3.2: 反事实生成 — VCI vs CVAE (公理 A1)

基于 L3 神经场编码的概念空间，VCI (端到端反事实) vs CVAE (已知不适合)。

- **成功标准 (C)**: VCI 精度 > CVAE; 外生噪声正确外溯
- **预算**: 2 GPU·天

### E3.3: 因果发现 — ILS-CSL + LLM (公理 A1, A6)

LLM 辅助迭代因果结构学习。5-8 物体 MuJoCo 场景。

- **成功标准 (I)**: SHD < 2 (5 节点); LLM 每查询减少 SHD
- **预算**: 1 GPU·天 + LLM API

### E3.4: 非线性因果抽象 (公理 A1, A2) — **S 级**

L3 (14 维神经场) → A (非线性抽象映射) → L4 (4 维因果概念)。

**测试**: L4 中 do(碰撞=1) 的效果是否等于 L3 中对应干预的效果。

- **成功标准 (S)**: 干预等效误差 <15%; |L4变量| ≪ |L3变量| 但保持因果结构
- **止损 (Day 12)**: 若失败 → 接受线性抽象 + 手工非线性特征
- **预算**: 2 GPU·天

## 第四部分: L5 元认知实验

### E4.1: meta-d' 校准 (公理 A9)

L3 预测任务 + L5 置信度 → meta-d' 信号检测论分析。

- **成功标准 (C)**: meta-d' ≠ 0; SelfModel precision ≥ WorldModel precision + ε
- **预算**: 1 GPU·天

### E4.2: 全局工作空间 — GLW 广播 (公理 A2)

对比 GLW 广播 vs 逐层传播的信息完整性和延迟。

- **成功标准 (I)**: GLW 信息完整性 > 逐层; 广播延迟 <5ms
- **预算**: 1.5 GPU·天

### E4.3: 认知拒绝 — "不知道" 机制 (公理 A9, A10) — **S 级**

OOD 场景 → uncertainty > threshold → 拒绝行动 vs 随机猜测。

- **成功标准 (S)**: OOD 拒绝率 >90% (in-dist <5%); 有 meta-d' 的失败率 < 无 meta-d' 的 50%
- **预算**: 1 GPU·天

## 第五部分: 集成实验

### E5.1: 全栈五层端到端 — **S 级**

5 球因果 Pong → L1(感知)→L2(行动)→L3(世界模型)→L4(因果)→L5(元认知) 全链。

- **成功标准 (S)**: T_cycle ≤ 50ms; 有高层 (L4+L5) 成功率 > 仅低层 (L2+L3); 紧急降级正确触发
- **预算**: 3 GPU·天

### E5.2: 破坏性测试 — 逐层攻击 (公理 A10)

| 层 | 攻击 | 期望行为 |
|----|------|---------|
| L1 | 雪花屏 | 拒绝 → 用 L3 预测器虚拟感知 |
| L2 | 动作偏置注入 | L5 检测 diverging → 紧急降级 |
| L3 | 世界模型投毒 | L4 检测因果不一致 → ALERT |
| L4 | 因果图假边 | meta-d' 检测置信度下降 |
| L5 | 自我模型篡改 | 多源验证机制 |

- **成功标准 (S)**: 单层攻击时全局退化 ≤30%; 检测 <3 周期
- **预算**: 2 GPU·天
